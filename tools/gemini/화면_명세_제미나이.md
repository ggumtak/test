## 1. 모달 전체 화면 틀 & 모든 고정 UI 문구 확정본

### 1-1. 전체 모달 레이아웃 틀 (상단 고정 + 본문 스크롤 + 하단 1줄)

기존에 하단 2줄이 화면을 잡아먹고 붉은 한글 발음이 시선을 어지럽히던 구조를 아래 틀로 완전히 교체합니다.

```text
┌──────────────────────────────────────────────────────────┐
│ [←]  写真  しゃしん  [🔊]                    [한]  [☆] │ ← 상단 헤더 (고정, 1줄)
│ [ 写 ]  [ 真 ]  [ AI 설명 ]                              │ ← 빠른 이동 칩 (AI 설명 열렸을 때만 표시)
├──────────────────────────────────────────────────────────┤
│  ┌────────┐  베낄 사                                     │ ← 본문 스크롤 영역
│  │        │  베끼다, 찍다(사진), 묘사하다 · 정자 寫      │   (기본 최대 높이 62% /
│  │   写   │                                              │    AI 설명·질문 시 82%로 자동 확장)
│  │ (색상) │  단어    しゃ                                │
│  │        │  음      シャ · 写真(しゃしん) 사진          │   ※ 좌측 [큰 한자 + 획순 ▸] 열은
│  └────────┘  훈      うつす · 写(うつ)す 베끼다          │      해당 한자 설명을 스크롤하는 동안
│    획순 ▸            읽기 더 보기 (3) ▸                  │      상단에 붙어 따라옴 (Sticky)
│              구성    冖(덮개) + 与(줄 여) · 부수 冖 민갓머리 ▸
│              외우기  덮개(冖) 아래서 원본을 그대로 옮겨 적어 주는(与) 모습 → 베끼다
│              확장    与(줄 여 · ヨ · 給与) / 誉(명예 예 · ヨ · 名誉) ▸
│              닮은꼴  与(줄 여: 위 덮개 冖 없음) ▸
│              유래 ▸  (기본 접힘 · 탭하면 아래로 펼쳐짐)
│              5획 · 초등 3학년
│              copy, be photographed, describe ⇄ 한
│  ──────────────────────────────────────────────────────  │
│  (다음 한자 真 카드...)                                  │
│  ──────────────────────────────────────────────────────  │
│  예문 보기 ▸                                             │
│  (AI 설명 본문 / 질문 대화 영역...)                      │
├──────────────────────────────────────────────────────────┤
│  [ 일본어사전 ]  [ 한자사전 ]  [ AI 설명 ]  [ 질문 ]     │ ← 하단 고정 바 (1줄만 유지)
└──────────────────────────────────────────────────────────┘
```

### 1-3. 필수 레이아웃 보정 규칙 3가지
1. **좌측 큰 한자 Sticky 안전 수식**: 스크롤 시 `maxShift = (row.height - leftCol.height).coerceAtLeast(0)`을 먼저 구한 뒤 `leftCol.translationY = (scrollY - rowTop).coerceIn(0, maxShift).toFloat()`를 적용합니다 (`유래`가 접혀 오른쪽 줄 높이가 짧을 때 음수 범위 크래시 방지, 레이아웃 변경 시마다 재계산).
2. **스크롤바 우측 글자 잘림 제거**: `CappedScrollView`에 `SCROLLBARS_OUTSIDE_OVERLAY`를 지정하고 본문 우측 패딩(`paddingEnd`)을 `10dp` 추가해 오른쪽 끝 글자가 스크롤바에 절대 잘리지 않게 합니다.
3. **모달 높이 자동 확장**: 기본 조회 시 최대 높이 `62%`, `AI 설명` 또는 `질문` 창이 열리면 최대 높이를 `82%`로 넓힙니다.

## 2. 개별 한자 카드의 새 구조 틀 & 항목별 문구 완성본

### 2-1. 개별 한자 카드의 새 위계 틀

기존에 암기 핵심인 `외우기`가 장황한 `유래` 밑에 파묻혀 있던 구조를 뒤집어, **스크롤 없이 한 화면에서 「뜻 → 읽기 → 부품 조립 → 이미지 연상 → 확장 한자」까지 끝나는 틀**로 바꿉니다.

| 순서 | 좌측 라벨명 | 우측 내용 표시 양식 (틀) | 클릭 동작 및 표시 원칙 |
| :---: | :--- | :--- | :--- |
| **1** | *(표제)* | **`베낄 사`** (굵게, 강조색) | 기존 유지 |
| **2** | *(뜻·정자)* | `뜻 베끼다, 찍다(사진), 묘사하다 · 정자 寫` (작은 회색) | 정자가 신자체와 같으면 `· 정자` 생략 (기존 유지) |
| **3** | **`단어`** | `しゃ` *(한글 켰을 때만 `しゃ(샤)` 연한 회색 병기)* | 현재 선택된 단어 안에서의 읽기 |
| **4** | **`음`** / **`훈`** | `シャ · 写真(しゃしん) 사진`<br>`うつす · 写(うつ)す 베끼다`<br>`읽기 더 보기 (N) ▸` | 상용 빈도 높은 읽기와 대표 단어 1개씩만 우선 노출, 덜 쓰는 읽기는 `읽기 더 보기 (N) ▸` 안에 접음 |
| **5** | **`구성`** | `冖(덮개 · 뜻) + 与(줄 여 · 소리) · 부수 冖 민갓머리 ▸`<br>*(단일 글자일 때)* `부수 目 눈목 ▸` | 기존 `부수` 행을 여기에 통합. **일본어 부수명(`わかんむり` 등) 완전 삭제**. 부품 색상(부수=붉은 강조색, 소리=파랑)은 좌측 큰 한자 그림과 일치. **줄 전체 탭 시 같은 부수 한자 목록 펼침/접힘** |
| **6** | **`외우기`** | `덮개(冖) 아래서 원본을 그대로 옮겨 적어 주는(与) 모습 → 베끼다` | **`구성` 바로 아래로 이동 (핵심)**. 옛 정자체·벽자가 아닌 **지금 눈에 보이는 신자체 조각**만으로 그림이 그려지는 1줄 연상문 |
| **7** | **`확장`** | `慎(삼갈 신 · シン · 慎重) / 鎮(진압할 진 · チン · 鎮圧) ▸` | **신규 항목 (기존 `소리 계열` 대체·확대)**. ① 같은 소리 부품+같은 음 → ② 같은 소리 부품+다른 음 → ③ 이 한자가 부품으로 들어간 상용한자 순으로 최대 3개(`tools/build_expand_data.py` → `assets/expand.tsv`). **탭 시 큰 글자 나란히 비교 카드 펼침**, 비교 카드 속 개별 한자 탭 시 그 한자로 이동 |
| **8** | **`닮은꼴`** | `直(곧을 직) / 具(갖출 구) ▸` *(또는 라벨 `닮은 한자`)* | `확장` 바로 아래 배치. 탭 시 나란히 비교 카드 펼침, 개별 한자 탭 시 이동 |
| **9** | **`유래 ▸`** | 기본 접힘: `유래 ▸` *(작은 회색 글씨)*<br>탭하여 펼침(`유래 ▾`): 정돈된 어원 1~2문장 | **최하단 이동 + 기본 접힘**. 탭했을 때만 본문 노출 |
| **10** | *(메타)* | `5획 · 초등 3학년`<br>`copy, be photographed, describe ⇄\u00A0한` | 기존 유지 (`⇄\u00A0한` 줄바꿈 방지 공백 필수) |

### 2-2. 실제 화면 텍스트 개편 전 → 개편 후 완성본 대조 (`写`, `真`)

현재 앱 데이터(`origin.tsv`, `parts.tsv` 등)에 들어 있는 벽자(`舄`, `匕`, `鼎`)와 추측성 사족(`~이라는 의견`, `확실하지 않음`)을 어떻게 고쳐야 직관적으로 읽히는지 보여주는 **실제 완성 원고 기준**입니다.

#### 예시 A: `写真`의 첫 글자 `写` (베낄 사)

- **개편 전 (현재 화면 — 벽자·중복·산만함)**
  - `부수`: `冖 민갓머리(덮다) · わかんむり(와칸무리) · 여기서는 '집 宀을 줄인 꼴'`
  - `구성`: `冖(집 宀을 줄인 꼴 · 뜻) + 与(舄을 줄인 꼴 · 소리 セキ)`
  - `유래`: `뜻+소리: 원래 글자 寫는 宀(집)이 뜻, 舄(セキ)이 소리. 본래 옮겨 둠, 뒤에 베낌. 일본에서는 宀을 冖로, 舄을 与 꼴로 줄여 씀.`
  - `외우기`: `빌린 책을 집(冖)에서 그대로 옮겨 써 주는(与) → 베끼다`

- **개편 후 (새 확정 틀과 텍스트)**
  - `구성`: `冖(덮개 · 뜻) + 与(줄 여 · 줄임꼴)  · 부수 冖 민갓머리 ▸`
  - `외우기`: `지붕 덮개(冖) 아래서 빌린 책을 그대로 베껴 주는(与) 모습 → 베끼다·찍다`
  - `확장`: `与(줄 여 · ヨ · 給与) / 誉(명예 예 · ヨ · 名誉) ▸`
  - `닮은 한자`: `与(줄 여) ▸`
  - `유래 ▸` *(펼쳤을 때)*: `정자(寫)는 집 안에 물건을 그대로 옮겨 둔다는 데서 '글이나 모습을 베끼다·사진 찍다'라는 뜻이 됨. 일본 신자체에서 윗부분은 冖, 아랫부분은 与 모양으로 줄여 씀.`

#### 예시 B: `写真`의 두 번째 글자 `真` (참 진)

- **개편 전 (현재 화면 — 모호한 학설 나열로 암기 방해)**
  - `부수`: `目 눈 목 · め(메)`
  - `구성`: `十(匕가 변한 꼴이라는 의견) + 具(솥 鼎이 변한 꼴이라는 의견 · 안에 부수 目)`
  - `유래`: `유래 불확실: 匕+鼎으로 보는 의견 등이 있으나 확실하지 않음(그러면 위 十은 匕, 아래는 솥 鼎이 변한 꼴). 참·진짜의 뜻.`
  - `외우기`: `열(十) 가지를 빠짐없이 갖춘(具) 것만 → 진짜·참`

- **개편 후 (새 확정 틀과 텍스트)**
  - `구성`: `十(열 십) + 具(갖출 구 · 안에 부수 目)  · 부수 目 눈목 ▸`
  - `외우기`: `열(十) 가지를 빈틈없이 다 갖춘(具) 알짜배기 → 참·진짜`
  - `확장`: `慎(삼갈 신 · シン · 慎重) / 鎮(진압할 진 · チン · 鎮圧) / 填(메울 전 · テン · 充填) ▸`
  - `닮은 한자`: `直(곧을 직) / 具(갖출 구) ▸`
  - `유래 ▸` *(펼쳤을 때)*: `속이 빈틈없이 꽉 찬 그릇의 모습에서 출발해 '거짓 없이 알차다 → 참·진짜'라는 뜻으로 굳어짐.`

### 2-3. 한자 데이터(`구성`·`외우기`·`유래`) 문구 정비용 규칙 (데이터 스크립트·배치 교정 시 적용)
기존 TSV 자산의 설명 문구를 다듬거나 새로 생성할 때는 아래 4원칙을 적용합니다.
1. **벽자 노출 금지**: 상용한자 밖의 옛 부속 글자(`舄`, `匕`, `鼎` 등)는 `구성`과 `외우기`에 절대 쓰지 말고, 현재 일본 신자체에서 눈에 보이는 조각(`冖 + 与`, `十 + 具`, `尚 + 儿`)으로만 직관적으로 표기합니다.
2. **추측성 군더더기 삭제**: `~라는 의견`, `확실하지 않음`, `알려져 있지 않음` 같은 문구는 모두 걷어내고 핵심 의미 변화만 1~2문장으로 간결히 적습니다.
3. **사전 분류용 부수 단서 보존**: `到`의 `刂`처럼 부수가 소리 부품 안에 들어 있어 뜻과 무관한 분류용 부수일 때는 `· 부수 刂 선칼도방(찾기용)`처럼 짧게 표시합니다.
4. **한글 독음 괄호 미포함**: TSV 원본과 생성 텍스트 안의 가나 옆에는 한글 발음 괄호를 넣지 않습니다(앱의 `한` 토글 설정이 담당).

### 3-1. `KanjiText.SYSTEM_PROMPT` 확정 전문 (코드에 그대로 복사해 교체)

```text

[출력 형식]
【핵심 뜻】
```

### 3-2. 화면 렌더링 스타일 규칙 (`Rich.kt` & `LookupActivity.rich()`)
위 출력 텍스트가 화면에 그려질 때 아래 4가지 시각 규칙이 정확히 적용되어야 합니다.
1. **`【섹션 제목】`**: 강조색(`pal.accent`) + 굵게, 섹션 위쪽 여백 확보.
2. **`・` 목록 줄**: `・` 뒤에 공백이 있든 없든(`・단어`, `・ 단어`) 모두 목록으로 인식해 깔끔하게 내어쓰기(hanging indent) 적용.
3. **`💡 연상:` 줄**: 앞머리 `💡 연상:`은 강조색(`pal.accent`) + 굵게 표시하고, 줄 전체는 목록처럼 들여쓰기해 한눈에 띄게 강조.
4. **`①` ~ `⑩` 소제목 줄**: 한자별 소제목(`① 名 (이름 명)`) 전체를 굵게 표시하되, 괄호 안 한글 `(이름 명)`은 가나 읽기가 아니므로 일반 괄호 텍스트로 유지.
