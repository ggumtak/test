# 장면에서 뜻을 미리 말하던 지금 외우기 → Gemini 줄(한자, 지금, 새). 한 줄씩 읽어 一 面 世 初 頂 示는 뺌(새 줄도 뜻을 말하거나 글자 자체를 부품으로 씀).

文	사람(亠乂) 가슴에 새긴 X자 무늬 → 무늬·글	사람 가슴(亠乂)에 엇갈려 새긴 빗금 → 무늬·글
言	입(口) 위로 말풍선 줄(亠·二)이 → 말	입 위로 소리 물결(言)이 퍼져 나가는 → 말
招	손(扌)짓하며 '이리 와!' 부르는(召) → 부르다·초대하다	손(扌)을 흔들며 반갑게 이름을 외쳐(召) 손님을 청하는 → 부르다·초대하다
番	짐승 발바닥(田)이 꾹꾹 찍은 발자국(釆)이 차례로 → 차례·번호	밭(田)길에 찍힌 짐승 발자국(釆)을 하나둘 세어 매긴 → 차례·번호
寄	기이한(奇) 손님이 집(宀)에 들르니 → 들르다·붙다	기이한(奇) 손님이 남의 집(宀) 처마에 잠깐 머무는 → 들르다·붙다
七	막대(一)를 굽은 칼(乙)로 싹둑싹둑 일곱 토막 → 일곱	막대(一)를 굽은 칼(乙)로 싹둑 자른 토막 수 → 일곱
氷	물(水)에 얼음 조각(丶) 하나 → 얼음	찬 바람 분 물(水) 위에 꽁꽁 맺힌 차가운 점(丶) → 얼음
横	문에 노란(黄) 나무(木) 막대를 가로로 지른 → 가로	누런(黄) 통나무(木)를 길목에 옆으로 길게 뉘어 막은 방향 → 가로
星	밤하늘에 새로 태어난(生) 반짝 별빛(日) → 별	해(日) 진 밤하늘에 새로 태어나(生) 반짝이는 빛 → 별
過	입 비뚤어진(咼) 채 졸다 내릴 역을 지나간(辶) → 지나다·지나치다	비뚤어진 입(咼)으로 졸다 내릴 역을 넘어 간(辶) → 지나다·지나치다
針	쇠(金)바늘(十)에 실을 꿰어 한 땀 한 땀 → 바늘	가느다란 쇠(金) 꼬챙이(十) 귀에 실을 꿰어 천을 깁는 도구 → 바늘
家	집(宀) 안에 돼지(豕)를 들여 함께 사는 → 집	지붕(宀) 아래 돼지(豕)까지 기르며 식구가 모여 사는 곳 → 집
厘	벼랑(厂) 위에서 내려다본 마을(里)이 티끌만 한 → 티끌·리	높은 벼랑(厂) 위에서 내려다본 마을(里)처럼 아주 자그마한 눈금 → 티끌·리
孔	아이(子)가 굽은(乙) 젖가슴의 젖구멍을 쪽쪽 → 구멍	아이(子)가 굽은 선(乙) 모양의 호리병 주둥이를 들여다보는 틈 → 구멍
表	옷(衣) 겉으로 털(二丨)이 삐죽 드러난 → 겉	옷(衣) 바깥쪽으로 짐승 털(二·丨)이 드러나 보이는 면 → 겉
壱	병(士冖) 밑에 숟가락(匕) 딱 하나 → 하나	항아리(士·冖) 밑바닥에 숟가락(匕)을 단 한 개만 꽂아 둔 수 → 하나
矢	뾰족한 촉(丿一) 아래 깃 달린 화살대(大) → 화살	뾰족한 촉과 깃 달린 대(矢)가 시위를 떠나 날아가는 → 화살
肩	짐 메는 어깨(戸) 아래 두툼한 살(月)이 붙은 → 어깨	짐을 얹는 관절(戸) 아래 단단한 살(月)이 받쳐 주는 부위 → 어깨
事	도구(一·口) 달린 장대(亅)를 손(⺕)에 쥐고 일하러 나서는 → 일	연장(一·口) 달린 장대(亅)를 손(⺕)에 쥐고 맡아 하는 직무 → 일
倍	사람(亻)이 벌떡 서서(立) 입(口)으로 '곱빼기요!' → 배·곱	사람(亻)이 몫을 가르는 소리(咅) 외치며 두 몫으로 불리는 → 배·곱
己	구불구불한 끈(己)처럼 내 몸을 웅크린 → 자기·몸	구부린 끈(己)처럼 내 쪽으로 팔을 감싸 가리키는 자신 → 자기·몸
久	뒤에서 붙잡힌(乀) 사람(ク)이 오래도록 못 떠나는 → 오래	등 뒤에서 받침대(久)로 고여 세월이 흘러도 변치 않는 → 오래
間	밤에 문(門) 틈 사이로 달빛(日)이 새어 드는 → 사이	두 짝 문(門)이 벌어진 틈으로 해(日)가 비쳐 드는 틈새 → 사이
際	두 언덕(阝)이 맞닿은 곳에서 제사(祭)를 지낼 때 → 때·사이	두 언덕(阝) 경계선에서 하늘에 제사(祭) 올리는 바로 그 무렵 → 때·사이
丈	손(乂)을 자(一)에 대고 열 뼘을 잰 어른 키 → 길이·어른	자와 손(一·乂)으로 열 자 높이를 재듯 늠름하게 자란 사내 → 길이·어른
朕	'짐이 명한다, 배(月) 틈을 도구(丷天)로 메워라!' → 나·짐	큰 배(月) 틈을 메우는 도구(丷·天) 쥔 천하의 황제 → 나·짐
鼻	밭(田)일 하던 두 손(廾)을 코(自)에 대고 킁킁 → 코	자기(自) 얼굴 한복판에 숨길을 내어 준(畀) 봉우리 → 코
頃	해 질 무렵 사람(匕)이 졸려 머리(頁)를 꾸벅 → 무렵	기다리던 사람(匕)이 고개와 머리(頁)를 기웃할 만큼 짧은 사이 → 무렵
茂	풀(艹)이 무릎까지 무성하게(戊) 자란 → 무성하다·우거지다	들판의 풀(艹)이 무성함(戊)을 뽐내며 허리 높이까지 자란 → 무성하다·우거지다
輪	바퀴살이 차례(侖)대로 가지런히 박힌 수레(車)의 → 바퀴	살이 차례(侖)대로 둥글게 박혀 수레(車)를 굴리는 동그란 테 → 바퀴
未	가지만 무성하고 열매는 아직 안 열린 나무(木) → 아직	가지 끝(未)만 무성하고 열매는 여물지 않은 상태 → 아직
雷	비(雨) 구름 속에서 천둥(田)이 우르릉 쾅쾅 → 천둥	먹구름 비(雨) 속에서 들판을 뒤흔들며 벼락(田)이 우르릉 쾅 치는 소리 → 천둥
万	막대(一)에 갈고리로 꿰어 매단 엽전 만 냥 → 만	가로대 아래 갈고리(万)로 엽전 꾸러미를 꿴 큰 수 → 만
斑	구슬(王) 두 알 사이에 무늬(文)가 얼룩덜룩 → 얼룩	고운 구슬(王)과 구슬(王) 사이에 짙은 무늬(文)가 점점이 박힌 자국 → 얼룩
奈	나무(大)에 능금은 보이는데(示) 어찌 딸까 → 어찌	큰 나무(大) 꼭대기에 보일(示) 듯 말 듯 매달려 따기 힘든 열매 → 어찌
由	등잔(日·丨) 불빛을 따라 길을 지나는 → 말미암다·지나다	등잔(日·丨)에 심지가 꽂혀 불빛이 피어오르는 까닭 → 말미암다·지나다
盾	방패(厂·十) 뒤에 숨어 눈(目)만 빼꼼 → 방패	넓은 가림판(厂·十) 뒤에 몸을 숨기고 눈(目)만 빼꼼 내민 호신구 → 방패
繊	실(糸)을 창(戈)으로 가늘게 쪼개니 → 가늘다	가는 창(土·业·戈) 끝보다 얇게 잣아 올린 가느다란 명주실(糸) → 가늘다
