# 부품 이름 통일 · batch-05 (21자, 구성 줄도 그 이름을 쓰는 글자: 고정 이름으로 자연스럽게 안 되면 '유지')

## 平 = 평평하다
이미 이 이름으로 쓰는 글자 1자. 예: 坪 흙(土)땅을 평평(平)히 고른 넓이 → 평

### 評 (평할 평)
구성: 言(말 · 뜻) + 平(공평 · 뜻·소리 ヘイ)
유래: 뜻+소리: '공평하게 따져 말함에서 평하다'를 뜻함.
지금 외우기: 심사위원이 공평(平)하게 점수를 매기며 하는 말(言) → 평가
부품 이름: 平 = **평평하다** ← 지금은 '공평' [구성도 '공평'] / 言 = 말


## 侖 = 차례
이미 이 이름으로 쓰는 글자 2자. 예: 輪 살이 차례(侖)대로 둥글게 박혀 수레(車)를 굴리는 동그란 테 → 바퀴 ／ 倫 사람(亻)들이 어른부터 차례(侖)대로 앉는 → 윤리·인륜

### 論 (논할 론)
구성: 言(말 · 뜻) + 侖(이치 · 뜻·소리 リン)
유래: 뜻+소리: 言(말)이 뜻, 侖(リン, 이치)은 소리도 내고 뜻도 보탬. 이치에 맞게 따짐.
지금 외우기: 이치(侖)에 맞는지 말(言)로 하나하나 따지는 → 논하다
부품 이름: 侖 = **차례** ← 지금은 '이치' [구성도 '이치'] / 言 = 말


## 曲 = 굽다
이미 이 이름으로 쓰는 글자 1자. 예: 農 허리를 굽혀(曲) 조개 농기구(辰)로 밭을 일구는 → 농사

### 豊 (풍성할 풍)
구성: 曲(담은 제물 · 모양) + 豆(굽 그릇 · 모양)
유래: 그림: 원래 글자는 豐. 굽 높은 그릇(豆)에 곡식과 제물(曲)을 수북이 담은 모양에서 풍성함을 뜻함.
지금 외우기: 굽 높은 그릇(豆)에 제물(曲)을 산처럼 수북이 쌓은 → 풍성하다
부품 이름: 豆 = 그릇 / 曲 = **굽다** ← 지금은 '제물' [구성도 '담은 제물']


## 辛 = 죄
이미 이 이름으로 쓰는 글자 2자. 예: 辞 혀(舌)로 죄(辛)를 따지자 '그만두겠소' 하는 → 말·그만두다 ／ 宰 집(宀) 안 일을 죄인(辛)이 도맡아 꾸리는 → 다스리다·재상

### 辣 (매울 랄)
구성: 辛(맵다 · 뜻) + 束(묶음 · 소리 ラツ)
유래: 뜻+소리: 辛(맵다)가 뜻, 束 부분이 소리(剌(ラツ)을 줄인 꼴이라는 의견이 있음). 맛이 몹시 매움.
지금 외우기: 매운(辛) 고추를 한 묶음(束)째 → 맵다·매섭다
부품 이름: 辛 = **죄** ← 지금은 '매운' [구성도 '맵다'] / 束 = 묶다


## 关 = 웃다
이미 이 이름으로 쓰는 글자 1자. 예: 咲 꽃이 입(口)을 활짝 벌리고 웃는(关) 듯 → 피다

### 送 (보낼 송)
구성: 关(받든 두 손 · 뜻) + 辶(가다 · 뜻)
유래: 뜻+뜻: 辶(가다)+关 꼴(본래 두 손으로 무엇을 받든 모양). 받들어 보냄(의견이 갈림).
지금 외우기: 두 손에 받든(关) 선물을 들려 길(辶)로 → 보내다
부품 이름: 关 = **웃다** ← 지금은 '받든' [구성도 '받든 두 손'] / 辶 = 가다


## 免 = 면하다
이미 이 이름으로 쓰는 글자 2자. 예: 勉 낙제를 면하려고(免) 밤새 힘(力)껏 책과 씨름하는 → 힘쓰다·공부하다 ／ 晩 해(日)가 져 고된 일을 면하는(免) → 저녁

### 逸 (달아날 일)
구성: 免(토끼 · 뜻) + 辶(가다 · 뜻)
유래: 뜻+뜻: 辶(가다)+兔(토끼). 토끼가 잘 달아남. 일본 글자는 兔의 점이 빠져 免처럼 보임.
지금 외우기: 토끼(免)가 깡충깡충 길(辶)로 내빼는 → 달아나다
부품 이름: 免 = **면하다** ← 지금은 '토끼' [구성도 '토끼'] / 辶 = 가다


## 垂 = 드리우다
이미 이 이름으로 쓰는 글자 2자. 예: 唾 입(口)에서 주르륵 드리워지는(垂) → 침 ／ 睡 눈(目)꺼풀이 드리워(垂) → 졸다

### 郵 (우편 우)
구성: 垂(변두리 · 뜻) + 阝(고을 · 뜻)
유래: 뜻+뜻: 변두리 땅에서 문서를 전하던 역참(말을 갈아타던 곳)을 뜻함.
지금 외우기: 변두리(垂) 고을(阝)까지 말 달려 편지를 전하는 → 우편
부품 이름: 垂 = **드리우다** ← 지금은 '변두리' [구성도 '변두리'] / 阝 = 고을


## 岡 = 언덕
이미 이 이름으로 쓰는 글자 2자. 예: 剛 언덕(岡)도 칼(刂)로 깎을 만큼 → 굳세다 ／ 綱 실(糸)을 언덕(岡)처럼 굵게 꼬아 그물을 버티는 → 밧줄·벼리

### 鋼 (강철 강)
구성: 金(쇠 · 뜻) + 岡(단단함 · 뜻·소리 コウ)
유래: 뜻+소리: 金(쇠)가 뜻, 岡(コウ, 단단함)은 소리도 내고 뜻도 보탬. 단단한 쇠를 뜻함.
지금 외우기: 두드릴수록 단단해지는(岡) 쇠(金) → 강철
부품 이름: 岡 = **언덕** ← 지금은 '단단해지는' [구성도 '단단함'] / 金 = 쇠


## 丘 = 언덕
이미 이 이름으로 쓰는 글자 1자. 예: 岳 언덕(丘) 위에 또 산(山)이 솟은 → 큰 산

### 兵 (군사 병)
구성: 丘(도끼 · 뜻) + 八(두 손 · 뜻)
유래: 뜻+뜻: 두 손으로 도끼를 든 모양(지금 모양은 丘+八 꼴). 본래 무기, 뒤에 병사를 뜻함.
지금 외우기: 두 손(八)으로 도끼(丘)를 번쩍 치켜든 → 병사
부품 이름: 八 = 손 / 丘 = **언덕** ← 지금은 '도끼' [구성도 '도끼']


## 冊 = 책
이미 이 이름으로 쓰는 글자 1자. 예: 柵 나무(木)를 책(冊)처럼 나란히 엮어 → 울타리

### 嗣 (이을 사)
구성: 口(입 · 뜻) + 冊(문서 · 뜻) + 司(맡을 사 · 소리 シ)
유래: 뜻+소리: 임금이 내린 임명 문서를 받아 뒤를 이음.
지금 외우기: 문서(冊)를 받고 입(口)으로 맹세하며 아버지 일을 맡는(司) → 잇다
부품 이름: 冊 = **책** ← 지금은 '문서' [구성도 '문서'] / 口 = 입 / 司 = 맡다


## 復 = 되돌리다
이미 이 이름으로 쓰는 글자 1자. 예: 覆 덮개(覀)를 덮었다가 홱 되돌려(復) 엎는 → 덮다·뒤집다

### 履 (신을 리)
구성: 尸(사람 · 뜻) + 復(신 신고 걸음 · 뜻)
유래: 뜻+뜻: 옛 사전에선 尸(사람)·彳(걷다)·夊(발)에 신 모양(舟)을 더한 글자라 함(彳·舟·夊가 지금의 復 꼴). 신, 신고 밟다.
지금 외우기: 사람(尸)이 발에 신을 꿰고 걷는(復) → 신다
부품 이름: 尸 = 몸 / 復 = **되돌리다** ← 지금은 '걷는' [구성도 '신 신고 걸음']


## 育 = 기르다
이미 이 이름으로 쓰는 글자 1자. 예: 撤 기르던(育) 화분을 손(扌)으로 쳐(攵) 걷어 내는 → 거두다

### 徹 (통할 철)
구성: 彳(가다 · 뜻) + 育(솥 · 뜻) + 攵(치다 · 뜻)
유래: 뜻+뜻: 본래 鬲(솥)을 손으로 치우는 모양. 鬲이 育으로 변하고 彳(길)이 붙음. '통하다'의 뜻.
지금 외우기: 길(彳) 막은 큰 솥(育)을 쳐(攵) 치워 끝까지 훤히 뚫린 → 통하다·꿰뚫다
부품 이름: 彳 = 가다 / 育 = **기르다** ← 지금은 '솥' [구성도 '솥'] / 攵 = 치다


## 或 = 경계
이미 이 이름으로 쓰는 글자 1자. 예: 域 땅(土)에 금을 긋고 창 들고 지키는 경계(或) 안 → 구역

### 惑 (미혹할 혹)
구성: 或(혹 혹 · 뜻·소리 ワク) + 心(마음 · 뜻)
유래: 뜻+소리: 或은 뜻도 보탬. 마음이 어지러움.
지금 외우기: 혹(或) 이 길일까, 마음(心)이 갈팡질팡 → 헷갈리다·미혹되다
부품 이름: 或 = **경계** ← 지금은 '혹' [구성도 '혹 혹'] / 心 = 마음


## 異 = 다르다
이미 이 이름으로 쓰는 글자 1자. 예: 翼 남다른(異) 깃(羽)을 양쪽으로 쫙 펼친 → 날개

### 戴 (받들 대)
구성: 𢦏(다칠 재 · 소리 サイ) + 異(머리에 인 이 · 뜻)
유래: 뜻+소리: 뜻은 異(머리에 인 사람), 소리는 𢦏(サイ). 머리에 이고 받듦.
지금 외우기: 다칠(𢦏)세라 왕관을 머리에 인 이(異)가 높여 모시는 → 받들다·이다
부품 이름: 𢦏 = 다치다 / 異 = **다르다** ← 지금은 '이' [구성도 '머리에 인 이']


## 原 = 근원
이미 이 이름으로 쓰는 글자 1자. 예: 願 샘의 근원(原) 앞에 머리(頁) 숙여 소원을 비는 → 바라다

### 源 (근원 원)
구성: 氵(물 · 뜻) + 原(샘 · 뜻·소리 ゲン)
유래: 뜻+소리: 氵(물)+原(본래 샘, ゲン). 原이 '들판'으로 쓰이자 氵를 더함.
지금 외우기: 샘(原)에서 물(氵)이 처음 솟아나는 곳 → 근원
부품 이름: 原 = **근원** ← 지금은 '샘' [구성도 '샘'] / 氵 = 물


## 孰 = 누구
이미 이 이름으로 쓰는 글자 1자. 예: 塾 누구(孰)든 흙(土)바닥에 모여 공부 → 학원

### 熟 (익을 숙)
구성: 孰(익히다 · 뜻·소리 ジュク) + 灬(불 · 뜻)
유래: 뜻+소리: 孰(본래 익히다, ジュク)+灬(불). 孰이 '누구'로 쓰이자 灬를 더함.
지금 외우기: 가마솥 불(灬)에 푹 익혀(孰) 젓가락만 대도 살이 발리는 → 익다
부품 이름: 灬 = 불 / 孰 = **누구** ← 지금은 '익혀' [구성도 '익히다']


## 尓 = 너
이미 이 이름으로 쓰는 글자 1자. 예: 弥 활(弓)시위를 너(尓) 쪽으로 당길수록 팽팽해지는 → 더욱

### 称 (일컬을 칭)
구성: 禾(벼 · 뜻) + 尓(들어 올림 · 뜻·소리 ショウ)
유래: 뜻+소리: 원래 글자 稱은 禾(벼)가 뜻, 爯(ショウ, 들어 올림)은 소리도 내고 뜻도 보탬. 곡식 무게를 잼, 뒤에 일컫다. 称은 爯을 尓로 바꿔 흔히 쓰던 간단한 글자임.
지금 외우기: 벼(禾)를 들어 올려(尓) 달고 무게를 외치는 → 일컫다·부르다
부품 이름: 禾 = 벼 / 尓 = **너** ← 지금은 '올려' [구성도 '들어 올림']


## 敬 = 공경
이미 이 이름으로 쓰는 글자 1자. 예: 驚 주인을 공경(敬)하며 얌전하던 말(馬)이 펄쩍 → 놀라다

### 警 (경계할 경)
구성: 敬(조심하다 · 뜻·소리 ケイ) + 言(말 · 뜻)
유래: 뜻+소리: 말로 일깨워 조심하게 함.
지금 외우기: 밤 보초가 수상한 그림자에 조심하라(敬)고 외치는 말(言) → 경계하다
부품 이름: 敬 = **공경** ← 지금은 '조심하라' [구성도 '조심하다'] / 言 = 말


## 釆 = 발자국
이미 이 이름으로 쓰는 글자 1자. 예: 番 밭(田)길에 찍힌 짐승 발자국(釆)을 하나둘 세어 매긴 → 차례·번호

### 釈 (풀 석)
구성: 釆(분별 · 뜻) + 尺(자 척 · 소리 エキ)
유래: 뜻+소리: 뜻은 釆(분별하다), 소리는 睪(エキ). 풀어서 가려냄. 일본에서는 睪을 尺으로 줄여 씀.
지금 외우기: 자(尺)로 재며 하나하나 분별해(釆) → 풀다·해석
부품 이름: 尺 = 자 / 釆 = **발자국** ← 지금은 '분별해' [구성도 '분별']


## 而 = 수염
이미 이 이름으로 쓰는 글자 1자. 예: 耐 법(寸)대로 수염(而)을 깎이는 벌도 꾹 → 견디다

### 需 (쓰일 수)
구성: 雨(비 · 뜻) + 而(사람 · 뜻)
유래: 뜻+뜻: 雨(비)+而(본래 사람 꼴). 옛 사전은 '비를 만나 멈춰 기다림'으로 풂(의견이 갈림). 뒤에 '구하다·쓰이다'.
지금 외우기: 비(雨)를 만나 멈춘 사람(而)이 우산을 찾는 → 구하다·수요
부품 이름: 雨 = 비 / 而 = **수염** ← 지금은 '사람' [구성도 '사람']


## 冋 = 창문
이미 이 이름으로 쓰는 글자 1자. 예: 尚 불 끈 뒤에도 창문(冋) 위로 연기가 갈라져(⺌) 오르는 → 아직

### 高 (높을 고)
구성: 亠+口(누각 지붕 · 모양) + 冋(누각 문 · 모양)
유래: 그림: 높게 지은 누각·망루(멀리 내다보는 높은 건물)의 모양임.
지금 외우기: 지붕(亠) 아래 창(口)과 문(冋)이 층층이 쌓인 누각 → 높다
부품 이름: 亠 = 지붕 / 口 = 창 / 冋 = **창문** ← 지금은 '문' [구성도 '누각 문']
