# 부품 이름 통일 · batch-02 (63자, 반드시 바꿀 글자)

## 示 = 제단
이미 이 이름으로 쓰는 글자 5자. 예: 祭 고기(月)를 손(又)으로 제단(示)에 바치는 → 제사 ／ 禁 숲(林) 속 제단(示)엔 들어가지 마라 → 금지
다른 것으로 인정한 글자(그대로 둠): 불 票尉

### 奈 (어찌 나)
구성: 大(나무 木이 바뀐 꼴 · 뜻) + 示(보일 시 · 소리 ナ)
유래: 뜻+소리: 본래 柰(능금나무)와 모양만 다른 같은 글자. 木(나무)가 뜻, 示가 소리이며 木이 大로 바뀜. '어찌'는 소리만 빌려 쓴 뜻.
지금 외우기: 큰 나무(大) 꼭대기에 보일(示) 듯 말 듯 매달려 따기 힘든 열매 → 어찌
부품 이름: 大 = 나무 / 示 = **제단** ← 지금은 '보일'


## 里 = 마을
이미 이 이름으로 쓰는 글자 6자. 예: 理 구슬(王)을 마을(里) 장인이 결 따라 깎는 → 이치 ／ 野 마을(里) 밖에 소를 미리(予) 풀어 둔 넓은 → 들판

### 重 (무거울 중)
구성: 千+里(사람이 자루 東을 진 꼴)
유래: 뜻+소리: 옛 청동기 글자는 사람(人)이 자루(東)를 진 모양, 東(トウ)이 소리. 무거움. 지금 꼴은 千+里처럼 변함.
지금 외우기: 곡식 자루를 지고 천(千) 리(里) 길을 가니 → 무겁다
부품 이름: 千 = 천 / 里 = **마을** ← 지금은 '리'


## 冂 = 틀
이미 이 이름으로 쓰는 글자 2자. 예: 央 사람(大)이 테두리(冂) 한복판에 떡 버티고 선 → 가운데 ／ 両 가로대(一) 밑 틀(冂) 두 칸(山)에 말을 한 마리씩 맨 → 양쪽·둘

### 同 (같을 동)
구성: 冂+一(凡이 변한 꼴 · 뜻) + 口(입 · 뜻)
유래: 뜻+뜻: 凡(冂 꼴)+口(입). 자세한 뜻은 의견이 갈리나 '함께·같다'를 나타냄.
지금 외우기: 한(一) 지붕(冂) 아래 입(口) 모아 한목소리 내는 → 같다
부품 이름: 一 = 하나 / 冂 = **틀** ← 지금은 '지붕' / 口 = 입


## 由 = 지나다
이미 이 이름으로 쓰는 글자 6자. 예: 油 물(氵)을 지나(由) 위로 둥둥 떠오르는 → 기름 ／ 笛 대나무(竹) 구멍으로 숨이 지나가며(由) 삐리리 → 피리

### 届 (닿을 계)
구성: 尸(몸 · 뜻) + 由(말미암을 유 · 소리 カイ)
유래: 뜻+소리: 원래 글자 屆는 尸(몸)이 뜻, 凷(흙덩이, カイ)가 소리. 이르다. 일본에서는 凷를 由로 바꿔 씀.
지금 외우기: 이유(由)서를 들고 몸(尸)소 구청 창구까지 → 닿다·신고하다
부품 이름: 由 = **지나다** ← 지금은 '이유' / 尸 = 몸


## 匕 = 사람
이미 이 이름으로 쓰는 글자 4자. 예: 化 선 사람(亻)이 거꾸러진 사람(匕)으로 → 변하다 ／ 死 뼈(歹)만 남은 이 앞에 사람(匕)이 엎드린 → 죽음
다른 것으로 인정한 글자(그대로 둠): 숟가락 匂旨壱

### 老 (늙을 로)
구성: 耂+匕(지팡이 노인 · 모양)
유래: 그림: 허리 굽고 머리 긴 노인이 지팡이를 짚은 모양임.
지금 외우기: 늙은이(耂)가 지팡이(匕)를 짚고 → 늙다
부품 이름: 耂 = 늙은이 / 匕 = **사람** ← 지금은 '지팡이'


## 亠 = 지붕
이미 이 이름으로 쓰는 글자 3자. 예: 六 지붕(亠) 아래 팔(八)자로 벌린 기둥, 육각 움막 → 여섯 ／ 夜 저녁(夕) 지나 지붕(亠) 밑 사람(亻)이 이불(乀) 덮고 눕는 때 → 밤

### 交 (사귈 교)
구성: 亠+父(다리 꼰 이 · 모양)
유래: 그림: 사람(大)이 두 다리를 꼬고 선 모양. '엇갈리다·사귀다'를 뜻함.
지금 외우기: 머리(亠) 아래 두 다리를 X자로 엇갈려 꼰 사람(父) → 섞이다·사귀다
부품 이름: 亠 = **지붕** ← 지금은 '머리' / 父 = **아비** ← 지금은 '사람'


## 云 = 구름
이미 이 이름으로 쓰는 글자 5자. 예: 雲 비(雨)를 머금고 뭉게뭉게 피어난 구름(云) → 구름 ／ 転 수레(車)바퀴가 구름(云)처럼 굴러가는 → 구르다

### 伝 (전할 전)
구성: 亻(사람 · 뜻) + 云(이르다 · 소리 セン)
유래: 뜻+소리: 원래 글자 傳은 亻(사람)이 뜻, 專(セン)이 소리. 사람을 거쳐 이어 보냄. 일본에서는 專을 云으로 바꿔 씀.
지금 외우기: 사람(亻)이 들은 말을 다음 사람에게 이르는(云) → 전하다
부품 이름: 亻 = 사람 / 云 = **구름** ← 지금은 '이르는'


## 士 = 선비
이미 이 이름으로 쓰는 글자 4자. 예: 仕 선비(士)인 사람(亻)이 나랏일을 맡아 → 섬기다·일하다 ／ 吉 선비(士)의 입(口)에서 나온 좋은 말 → 길하다
다른 것으로 인정한 글자(그대로 둠): 내다 売 / 가다 志

### 壮 (씩씩할 장)
구성: 丬(평상 · 소리 ショウ) + 士(남자 · 뜻)
유래: 뜻+소리: 원래 글자 壯은 士(남자)가 뜻, 爿(ショウ)이 소리. 씩씩한 남자. 일본에서는 爿을 丬로 줄여 씀.
지금 외우기: 나무판(丬)을 번쩍 들어 멘 남자(士) → 씩씩하다
부품 이름: 丬 = **평상** ← 지금은 '나무판' / 士 = **선비** ← 지금은 '남자' [구성도 '남자']


## ⺍ = 불꽃
이미 이 이름으로 쓰는 글자 2자. 예: 労 횃불(⺍) 밝힌 덮개(冖) 아래서 밤새 힘(力)을 쏟는 → 일하다 ／ 栄 불꽃(⺍) 같은 꽃이 지붕(冖)처럼 나무(木)를 덮은 → 번영

### 桜 (벚나무 앵)
구성: 木(나무 · 뜻) + ⺍+女(嬰을 줄인 꼴 · 소리 エイ)
유래: 뜻+소리: 원래 글자 櫻은 木(나무)가 뜻, 嬰(エイ)이 소리. 본래 앵두나무, 일본에서 벚나무로 씀. 일본 글자는 貝貝를 ⺍로 씀.
지금 외우기: 나무(木) 아래 꽃잎(⺍) 맞으며 선 여자(女) → 벚꽃
부품 이름: 木 = 나무 / ⺍ = **불꽃** ← 지금은 '꽃잎' / 女 = 여자


## 小 = 작다

### 歳 (해 세)
구성: 止(발 · 뜻) + 戌(도끼 · 소리 サイ) + 小(작은 발 · 뜻)
유래: 뜻+소리: 원래 글자 歲는 步(걸음)이 뜻, 戉(도끼)가 소리(옛 사전은 戌로 봄, 의견이 갈림). 해·나이. 일본에서는 속의 少 꼴을 小로 씀.
지금 외우기: 도끼(戌) 별이 발(止)과 작은 발(小)로 하늘을 돈 시간 → 해·나이
부품 이름: 戌 = **도끼창** ← 지금은 '도끼' / 止 = 발 / 小 = **작다** ← 지금은 '발' [구성도 '작은 발']


## 𠂉 = 사람
이미 이 이름으로 쓰는 글자 4자. 예: 塩 짠 흙(土)을 사람(𠂉)이 입(口)으로 맛보고 그릇(皿)에 → 소금 ／ 臨 사람(𠂉)이 눈(臣) 크게 뜨고 물건들(品)을 내려다보는 → 임하다

### 乞 (빌 걸)
구성: 𠂉+乙(气에서 한 획을 뺀 꼴)
유래: 빌린 글자: 气(김)에서 한 획을 뺀 꼴로, '구하다'의 뜻으로 빌려 씀.
지금 외우기: 고개(𠂉) 숙이고 허리 굽혀(乙) 손 내미는 → 구걸하다
부품 이름: 𠂉 = **사람** ← 지금은 '고개' / 乙 = 굽다


## 走 = 달리다
이미 이 이름으로 쓰는 글자 5자. 예: 起 몸(己)을 벌떡 일으켜 달려(走) 나가는 → 일어나다 ／ 赴 점(卜)을 쳐 '가라'고 나오자 곧장 달려가는(走) → 나아가다

### 徒 (무리 도)
구성: 彳(止와 합쳐 辵, 가다 · 뜻) + 走(土는 소리 ト, 아래는 止)
유래: 뜻+소리: 본래 辵(가다)가 뜻, 土(ト)가 소리. 走처럼 보이나 土+止이며, 彳과 이 止가 辵을 이룸. 수레 없이 걸어감, 뒤에 무리·헛되다.
지금 외우기: 수레도 없이 흙(走)길을 줄줄이 걸어가는(彳) 사람들 → 무리
부품 이름: 走 = **달리다** ← 지금은 '흙' / 彳 = 가다


## 共 = 함께
이미 이 이름으로 쓰는 글자 3자. 예: 洪 물(氵)이 함께(共) 한꺼번에 밀려오는 → 홍수 ／ 恭 두 손 모아 함께(共) 받드는 마음(⺗) → 공손

### 暴 (사나울 폭)
구성: 日(해 · 뜻) + 共+氺(두 손과 쌀 · 뜻)
유래: 뜻+뜻: 쌀을 내어 볕에 쬠(曝의 원래 글자). 뒤에 '사납다'. 아래가 共·氺 꼴로 변함.
지금 외우기: 쨍쨍한 해(日)에 두 손(共)으로 쌀(氺)을 말리는 → 사납다·드러내다
부품 이름: 日 = 해 / 共 = **함께** ← 지금은 '손' / 氺 = **물** ← 지금은 '쌀'


## 勹 = 감싸다
이미 이 이름으로 쓰는 글자 3자. 예: 句 입(口)에서 나온 말을 싸서(勹) 묶은 토막 → 구절 ／ 勾 감싼(勹) 팔(厶)이 갈고리처럼 → 굽다

### 匂 (냄새 내)
구성: 勹+匕(덮개와 수저)
유래: 일본에서 만든 글자: 일본에서 만든 글자. 韵(韻과 모양만 다른 같은 글자)의 오른쪽 匀이 변한 꼴로, '냄새·향'의 뜻으로 씀.
지금 외우기: 감싸 덮은(勹) 냄비에 숟가락(匕) 넣자 솔솔 → 냄새·향기
부품 이름: 勹 = **감싸다** ← 지금은 '덮은' / 匕 = 숟가락


## 比 = 나란하다
이미 이 이름으로 쓰는 글자 3자. 예: 鹿 지붕(广) 같은 뿔 아래 나란한(比) 다리 → 사슴 ／ 陛 흙(土)을 나란히(比) 쌓은 계단 언덕(阝) 위에 앉은 → 폐하

### 批 (비평할 비)
구성: 扌(손 · 뜻) + 比(견줄 비 · 소리 ヒ)
유래: 뜻+소리: 본래 손으로 치다, 뒤에 '따져 평하다'를 뜻함.
지금 외우기: 두 작품을 견주어(比) 손(扌)가락으로 짚어 가며 따지는 → 비평하다
부품 이름: 比 = **나란하다** ← 지금은 '견주어' / 扌 = 손


## 旦 = 아침
이미 이 이름으로 쓰는 글자 3자. 예: 担 아침(旦) 장에 팔 나물 지게를 손(扌)으로 어깨에 올리는 → 메다 ／ 但 아침(旦)에 웃통 벗고 바지 하나만 걸친 사람(亻) → 다만

### 昼 (낮 주)
구성: 尺(자 尺, 畫를 줄여 바꾼 꼴 · 뜻) + 旦(해 日이 든 꼴 · 뜻)
유래: 뜻+뜻: 원래 글자 晝는 畫(긋다)를 줄인 꼴+日(해). 해 뜬 동안을 그어 나눈 '낮'. 일본 글자는 尺+旦 꼴임.
지금 외우기: 해(旦)가 뜬 동안을 자(尺)로 금 그어 나눈 → 낮
부품 이름: 旦 = **아침** ← 지금은 '해' / 尺 = 자


## 毎 = 매양
이미 이 이름으로 쓰는 글자 4자. 예: 海 물(氵)이 매번(毎) 밀려오는 곳 → 바다 ／ 侮 사람(亻)을 매번(毎) 위아래로 훑고 코웃음 치는 → 업신여기다

### 梅 (매화 매)
구성: 木(나무 · 뜻) + 毎(매양 매 · 소리 マイ)
유래: 뜻+소리: 뜻은 木(나무)이고 소리는 毎(マイ)임.
지금 외우기: 매(毎)해 눈 덮인 나무(木) 가지에 맨 먼저 피는 꽃 → 매화
부품 이름: 毎 = **매양** ← 지금은 '매' / 木 = 나무


## 业 = 실
이미 이 이름으로 쓰는 글자 2자. 예: 湿 해(日)에 널어 말리던 실(业)이 물(氵)에 → 젖다 ／ 顕 햇빛(日)에 실(业)을 비춰 머리(頁) 내밀고 보니 또렷이 → 나타나다

### 業 (업 업)
구성: 业+羊+木(장식 나무틀 · 모양)
유래: 그림: 악기를 매다는 큰 나무 틀의 장식 판 모양에서 출발해 이루는 일·학업을 뜻함.
지금 외우기: 나무(木) 틀 위 양(羊) 뿔 같은 장식(业) 다듬는 → 일
부품 이름: 木 = 나무 / 羊 = 양 / 业 = **실** ← 지금은 '장식'


## 凵 = 구덩이
이미 이 이름으로 쓰는 글자 1자. 예: 凶 구덩이(凵)에 X(乂) 표시, 빠지면 → 흉하다

### 歯 (이 치)
구성: 止(그칠 지 · 소리 シ) + 米+凵(이빨 · 뜻)
유래: 뜻+소리: 입 속 이를 그린 글자에 止(シ)를 소리로 더함. 일본에서는 아래 이 부분을 米 꼴로 줄여 씀.
지금 외우기: 입(凵) 속 쌀(米)알 같은 이가 멈춰(止) 박힌 → 이
부품 이름: 凵 = **구덩이** ← 지금은 '입' / 米 = 쌀 / 止 = 그치다


## 自 = 코
이미 이 이름으로 쓰는 글자 4자. 예: 自 코(自)를 가리키며 '나야!' → 스스로 ／ 首 윗부분 털(丷) 아래 눈코(自)가 달린 몸의 맨 꼭대기 → 머리·목

### 鼻 (코 비)
구성: 自(코 · 뜻) + 畀(줄 비 · 소리 ヒ)
유래: 뜻+소리: 코를 그린 自가 '스스로'로 쓰이자 소리 부품 畀(ヒ)를 더해 얼굴의 코를 나타냄.
지금 외우기: 자기(自) 얼굴 한복판에 숨길을 내어 준(畀) 봉우리 → 코
부품 이름: 自 = **코** ← 지금은 '자기' / 畀 = 준(이 글자에만 있는 부품: 그대로)


## 甫 = 모종 밭
이미 이 이름으로 쓰는 글자 3자. 예: 捕 모종 밭(甫)에 든 토끼를 손(扌)으로 덥석 → 잡다 ／ 浦 배가 물(氵)을 건너와 모종 밭(甫) 앞 뭍에 닻을 내리는 → 물가·포구
