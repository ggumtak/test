# 부품 이름 통일 · batch-01 (90자, 반드시 바꿀 글자)

## 一 = 하나
이미 이 이름으로 쓰는 글자 8자. 예: 百 하나(一)같이 흰(白) 머리, 백 살 → 백 ／ 同 한(一) 지붕(冂) 아래 입(口) 모아 한목소리 내는 → 같다
다른 것으로 인정한 글자(그대로 둠): 기준선 上下 / 땅 土生立才止丘 / 성 正

### 七 (일곱 칠)
구성: 一(가로획 · 모양) + 乙(굽은 획 · 모양)
유래: 빌린 글자: 가로획을 세로획이 끊는 모양으로 본래 '자르다'를 뜻함. 소리를 빌려 수 '일곱'으로 씀.
지금 외우기: 막대(一)를 굽은 칼(乙)로 싹둑 자른 토막 수 → 일곱
부품 이름: 一 = **하나** ← 지금은 '막대' / 乙 = **굽다** ← 지금은 '칼'

### 三 (석 삼)
구성: 一+一+一(가로획 셋 · 기호)
유래: 기호: 가로획 셋을 그어 수 '셋'을 나타냄.
지금 외우기: 막대(一) 세 개를 차곡차곡 쌓은 → 셋
부품 이름: 一 = **하나** ← 지금은 '막대'

### 本 (책 본)
구성: 木(나무 · 모양) + 一(뿌리 쪽 표시 · 기호)
유래: 기호: 木(나무)의 뿌리 쪽에 표시(一)를 더해 '뿌리·근본'을 가리킴.
지금 외우기: 나무(木) 뿌리에 한 줄(一) 표시 → 근본·책
부품 이름: 木 = 나무 / 一 = **하나** ← 지금은 '줄'

### 今 (이제 금)
구성: 人+一+フ(뒤집힌 입 등, 의견이 갈림)
유래: 빌린 글자: 일찍부터 소리를 빌려 바로 이때인 '지금'을 뜻하는 글자로 씀.
지금 외우기: 지붕(人) 밑 시계 두 바늘(一·フ)이 겹치며 땡 울리는 바로 이때 → 지금
부품 이름: 人 = 지붕 / 一 = **하나** ← 지금은 '바늘'

### 両 (두 량)
구성: 一+冂(멍에 틀 · 모양) + 山(두 칸 · 모양)
유래: 그림: 원래 글자 兩은 말 두 마리를 매는 수레 멍에(말 목에 얹는 나무) 모양(의견이 갈림). 짝을 이뤄 '둘'. 일본에서는 안을 山 꼴로 줄여 씀.
지금 외우기: 가로대(一) 밑 틀(冂) 두 칸(山)에 말을 한 마리씩 맨 → 양쪽·둘
부품 이름: 一 = **하나** ← 지금은 '가로대' / 冂 = 틀 / 山 = **산** ← 지금은 '칸' [구성도 '두 칸']

### 丙 (셋째 천간 병)
구성: 一+内(받침대 · 모양)
유래: 그림: 물건을 얹는 받침대나 물고기 꼬리 모양에서 순서를 매기는 셋째('병')로 빌려 씀.
지금 외우기: 금·은 다음으로 판(一) 얹은 받침대(内)에 오른 동메달 → 셋째·3등
부품 이름: 一 = **하나** ← 지금은 '판' / 内 = **안** ← 지금은 '받침대'

### 朱 (붉을 주)
구성: 丿+未(붉은 나무)
유래: 기호: 木(나무) 줄기 가운데에 획을 더해 줄기를 가리킴. 속이 붉은 나무에서 '붉다'의 뜻이 됨(의견이 갈림).
지금 외우기: 나무(木) 허리(一)를 베니 붉은 속살이 → 붉다·주홍
부품 이름: 木 = 나무 / 一 = **하나** ← 지금은 '허리'

### 更 (고칠 경)
구성: 一+曰+乂(丙과 攴이 합쳐 바뀐 꼴)
유래: 뜻+소리: 본래 㪅으로 攴(치다)가 뜻, 丙(ヘイ)이 소리. 고침, 뒤에 '다시·더욱'. 지금 글자는 그 모양이 바뀐 것.
지금 외우기: 한 줄(一)씩 말(曰)해 보며 틀린 곳에 X표(乂) → 고치다
부품 이름: 一 = **하나** ← 지금은 '줄' / 曰 = 말하다 / 乂 = **엇갈리다** ← 지금은 '표'

### 遣 (보낼 견)
구성: 中+一+㠯(안쪽 부분 · 소리 ケン) + 辶(가다 · 뜻)
유래: 뜻+소리: 辶(가다)가 뜻, 안쪽 부분(ケン)이 소리. 사람을 떠나보냄.
지금 외우기: 가운데(中)를 끈(一)으로 묶은 상자 짐(㠯)을 길(辶)로 → 보내다
부품 이름: 中 = 가운데 / 一 = **하나** ← 지금은 '끈' / 㠯 = **무리** ← 지금은 '짐' / 辶 = 가다


## 丿 = 삐침

### 少 (적을 소)
구성: 小(작은 점 셋 · 기호) + 丿(넷째 점 · 기호)
유래: 기호: 가장 오래된 모양은 작은 점 넷(지금은 小+丿 꼴). 小(작다)에서 갈라져 나와 '적다'를 나타냄.
지금 외우기: 작은 점 셋(小)에 한 점(丿) 더해도 겨우 넷 → 적다
부품 이름: 小 = **작다** ← 지금은 '셋' / 丿 = **삐침** ← 지금은 '점'

### 血 (피 혈)
구성: 丿(피 · 기호) + 皿(그릇 · 뜻)
유래: 기호: 제사 그릇(皿) 안에 담긴 붉은 액체를 짧은 획(丿)으로 가리켜 '피'를 나타냄.
지금 외우기: 그릇(皿) 안에 붉은 한 방울(丿)이 고인 액체 → 피
부품 이름: 皿 = 그릇 / 丿 = **삐침** ← 지금은 '방울'

### 着 (입을 착)
구성: 羊(艹가 변한 꼴 · 뜻) + 丿+目(者가 변한 꼴 · 소리 チャク)
유래: 뜻+소리: 著(艹가 뜻, 者가 소리)를 흔히 바꿔 쓰던 글자. 艹·者가 羊·目 꼴로 변함. 붙다·입다의 뜻을 맡음.
지금 외우기: 양(羊)털 옷을 걸쳐(丿) 눈(目) 밑까지 착 붙게 → 입다·붙다
부품 이름: 羊 = 양 / 丿 = **삐침** ← 지금은 '걸쳐' / 目 = 눈

### 失 (잃을 실)
구성: 丿+夫(삐끗한 손)
유래: 뜻+소리: 손에서 빠져나가 잃음. 모양이 변해 지금은 丿+夫 꼴임.
지금 외우기: 남편(夫)이 손에서 삐끗(丿) 놓친 → 잃다
부품 이름: 夫 = 사내 / 丿 = **삐침** ← 지금은 '삐끗'

### 必 (반드시 필)
구성: 心+丿(창 자루 · 모양)
유래: 그림: 본래 도끼나 창의 자루 모양으로 보며, 소리를 빌려 '반드시·꼭'의 뜻으로 씀.
지금 외우기: 마음(心)에 창 자루(丿)를 꽂듯 꼭 다짐한 → 반드시
부품 이름: 心 = 마음 / 丿 = **삐침** ← 지금은 '자루'

### 乏 (모자랄 핍)
구성: 丿+之(正을 뒤집은 꼴로 봄 · 기호)
유래: 기호: 옛 사전은 正(바르다)를 뒤집은 꼴로 봄(의견이 갈림). 바르지 못함, 모자람.
지금 외우기: 먼 길 가는(之) 나그네, 등짐은 달랑 하나(丿)뿐 → 모자라다
부품 이름: 之 = 가는 / 丿 = **삐침** ← 지금은 '하나'

### 升 (되 승)
구성: 丿+廾(자루 달린 되 · 모양)
유래: 그림: 자루 달린 되(국자)로 곡식을 뜨는 모양. 양을 재는 그릇임.
지금 외우기: 국자처럼 자루(丿) 달린 그릇(廾)으로 곡식을 푹 → 되
부품 이름: 丿 = **삐침** ← 지금은 '자루' / 廾 = **두 손** ← 지금은 '그릇'

### 寿 (목숨 수)
구성: 三+丿(壽에서 寸 위를 줄인 꼴) + 寸(壽 맨 아래의 寸)
유래: 뜻+소리: 원래 글자 壽는 老(늙다)를 줄인 꼴이 뜻, 아랫부분(チュウ)이 소리. 오래 삶. 일본에서는 寸 위를 三+丿 꼴로 크게 줄여 씀.
지금 외우기: 석(三) 줄 주름에 지팡이(丿) 짚고 마디(寸)마디 → 장수
부품 이름: 三 = 셋 / 丿 = **삐침** ← 지금은 '지팡이' / 寸 = 마디


## 口 = 입
이미 이 이름으로 쓰는 글자 78자. 예: 口 '아~' 하고 네모나게 쩍 벌린 입(口) → 입 ／ 右 오른손(𠂇)으로 밥을 입(口)에 넣는 → 오른쪽
다른 것으로 인정한 글자(그대로 둠): 그릇 合豆器 / 창 高向

### 回 (돌 회)
구성: 囗(소용돌이 바깥쪽 · 모양) + 口(소용돌이 안쪽 · 모양)
유래: 그림: 물이 빙빙 도는 소용돌이 모양임.
지금 외우기: 소용돌이가 바깥(囗)에서 안(口)으로 빙글빙글 감기는 → 돌다
부품 이름: 囗 = **에워싸다** ← 지금은 '바깥' [구성도 '소용돌이 바깥쪽'] / 口 = **입** ← 지금은 '안'

### 史 (역사 사)
구성: 口+乂(붓 쥔 손)
유래: 뜻+뜻: 손(又)에 기록 도구(中)를 쥔 모양. 본래 기록하는 관리, 뒤에 역사(의견이 갈림).
지금 외우기: 손(乂)에 기록 도구(口)를 쥐고 지난 일을 적는 → 역사
부품 이름: 乂 = **엇갈리다** ← 지금은 '손' / 口 = **입** ← 지금은 '도구'

### 革 (가죽 혁)
구성: 廿+口+十(펼친 가죽 · 모양)
유래: 그림: 짐승의 가죽을 벗겨 펼친 모양(머리·몸통·꼬리). 뒤에 '고치다'를 뜻함.
지금 외우기: 짐승 머리(廿)·몸통(口)·꼬리(十)를 쭉 펴 말린 → 가죽
부품 이름: 廿 = **스물** ← 지금은 '머리' / 口 = **입** ← 지금은 '몸통' / 十 = **열** ← 지금은 '꼬리'

### 亜 (버금 아)
구성: 一+口+丨+丨+一(열십자 방 · 모양)
유래: 그림: 원래 글자 亞는 무덤 속 방이나 제단을 위에서 본 모양으로 보는 의견이 많음(의견이 갈림). '버금(둘째)'은 빌린 뜻.
지금 외우기: 위아래 판(一·一)에 눌려 가운데(口)에 낀 둘째 → 버금·다음가다
부품 이름: 口 = **입** ← 지금은 '가운데'

### 培 (북돋울 배)
구성: 土(흙 · 뜻) + 咅(立+口 꼴 · 소리 バイ)
유래: 뜻+소리: 土(흙)이 뜻, 咅가 소리. 흙을 북돋아 줌.
지금 외우기: 모종 세워(立) 구덩이(口)에 흙(土)을 덮는 → 북돋우다·기르다
부품 이름: 立 = 서다 / 口 = **입** ← 지금은 '구덩이' / 土 = 흙


## 厶 = 나
이미 이 이름으로 쓰는 글자 8자. 예: 公 사사로운(厶) 욕심을 등지고(八) 모두를 위하는 → 공평·공공 ／ 台 내(厶)가 단상에 올라 입(口)으로 연설하는 → 받침대·무대
다른 것으로 인정한 글자(그대로 둠): 입구 去

### 能 (능할 능)
구성: 䏍(곰의 머리 厶와 몸 月 · 모양) + 匕+匕(곰의 발 · 모양)
유래: 그림: 머리(厶)·몸(月)·발(匕匕)을 갖춘 곰의 모양(熊(곰)의 원래 글자). 뒤에 '능하다'로 빌려 씀.
지금 외우기: 머리(厶)·몸(月)·발(匕匕) 갖춘 곰이 나무도 척척 → 능하다
부품 이름: 厶 = **나** ← 지금은 '머리' / 月 = 몸

### 窓 (창 창)
구성: 穴(구멍 · 뜻) + 厶+心(悤을 줄인 꼴 · 소리 ソウ)
유래: 뜻+소리: 穴(구멍)이 뜻, 悤(ソウ)의 줄인 꼴(厶+心)이 소리. 囱(창 모양)에서 나온 窗과 모양만 다른 같은 글자임.
지금 외우기: 답답한 마음(心)에 벽 구멍(穴)으로 코(厶)를 내밀고 바람 쐬는 곳 → 창
부품 이름: 心 = 마음 / 穴 = 구멍 / 厶 = **나** ← 지금은 '코'

### 勾 (굽을 구)
구성: 勹(丩가 변한 꼴 · 소리 コウ) + 厶(口가 변한 꼴 · 뜻)
유래: 뜻+소리: 句(굽다; 口가 뜻, 丩가 소리)와 모양만 다른 같은 글자로, 丩는 勹 꼴, 口는 厶 꼴로 씀. 句에서 갈라져 '굽다·걸다'의 뜻을 맡음.
지금 외우기: 감싼(勹) 팔(厶)이 갈고리처럼 → 굽다
부품 이름: 勹 = 감싸다 / 厶 = **나** ← 지금은 '팔'

### 鬼 (귀신 귀)
구성: 甶(큰 머리·탈 · 모양) + 儿(사람 · 모양) + 厶(뒤에 더해진 부분)
유래: 그림: 큰 머리(탈)를 쓴 사람의 모양. 죽은 이의 넋, 귀신. 厶는 뒤에 더해짐.
지금 외우기: 큰 탈(甶)을 쓴 사람(儿)이 몰래(厶) 다니는 → 귀신
부품 이름: 甶 = 탈(이 글자에만 있는 부품: 그대로) / 儿 = 사람 / 厶 = **나** ← 지금은 '몰래'


## 八 = 나누다
이미 이 이름으로 쓰는 글자 2자. 예: 公 사사로운(厶) 욕심을 등지고(八) 모두를 위하는 → 공평·공공 ／ 分 칼(刀)로 둘로 쪼개(八) → 나누다
다른 것으로 인정한 글자(그대로 둠): 손 共兵

### 六 (여섯 륙)
구성: 亠+八(움막 · 모양)
유래: 빌린 글자: 지붕 있는 움막을 그린 모양으로 봄. 소리를 빌려 수 '여섯'으로 씀.
지금 외우기: 지붕(亠) 아래 팔(八)자로 벌린 기둥, 육각 움막 → 여섯
부품 이름: 亠 = 지붕 / 八 = **나누다** ← 지금은 '팔'

### 貝 (조개 패)
구성: 目+八(자패라는 조개 · 모양)
유래: 그림: 자패라는 조개의 모양. 옛날에 돈으로 씀.
지금 외우기: 눈(目) 같은 껍데기에 다리 둘(八) → 조개
부품 이름: 目 = 눈 / 八 = **나누다** ← 지금은 '둘'

### 穴 (구멍 혈)
구성: 宀+八(땅굴 입구 · 모양)
유래: 그림: 땅을 파서 만든 집이나 굴의 입구 모양임.
지금 외우기: 땅 파고 지붕(宀) 얹은 굴에 뻥 뚫린 입구(八) → 구멍·굴
부품 이름: 宀 = 집 / 八 = **나누다** ← 지금은 '입구'

### 並 (나란할 병)
구성: 八+一+业(나란히 섬 · 뜻)

### 応 (응할 응)

유래: 뜻+소리: 원래 글자 應은 心(마음)이 뜻, 䧹(ヨウ, 매)가 소리. 마음으로 응함. 일본 글자는 广 안에 心만 남김.
지금 외우기: 부르면 매(广)가 마음(心)으로 알아듣고 날아오는 → 응하다
부품 이름: 广 = **집** ← 지금은 '매' / 心 = 마음


## 工 = 장인
이미 이 이름으로 쓰는 글자 9자. 예: 空 장인(工)이 천장에 구멍(穴)을 뻥 뚫어 텅 빈 → 비다·하늘 ／ 紅 장인(工)이 실(糸)을 새빨갛게 물들인 → 붉다
다른 것으로 인정한 글자(그대로 둠): 도구 左式

### 恐 (두려울 공)
구성: 工+凡(합쳐서 巩 · 소리 キョウ) + 心(마음 · 뜻)
유래: 뜻+소리: 두려워함.
지금 외우기: 공(工)든 탑이 모두(凡) 무너질까 마음(心) 졸이는 → 두렵다
부품 이름: 工 = **장인** ← 지금은 '공' / 凡 = **평범하다** ← 지금은 '모두' / 心 = 마음


## 囗 = 에워싸다
이미 이 이름으로 쓰는 글자 8자. 예: 図 사방을 에워싼(囗) 테두리 안에 고을(⺍乂) 길을 그린 → 그림·지도 ／ 国 성벽으로 에워싼(囗) 땅 안에 보배 구슬(玉)을 지키는 → 나라

### 四 (넉 사)
구성: 囗+儿(입김 呬를 그린 글자로 봄)
유래: 빌린 글자: 입김이 나오는 입 모양을 그린 글자를 수 '넷'으로 빌려 쓴 것으로 봄.
지금 외우기: 네모 상(囗) 아래 다리(儿)가 모서리마다 하나씩 → 넷
부품 이름: 囗 = **에워싸다** ← 지금은 '상' / 儿 = 다리


## 欠 = 벌리다
이미 이 이름으로 쓰는 글자 10자. 예: 歌 가락(哥)에 맞춰 입을 크게 벌리고(欠) 목청껏 부르는 가락 → 노래 ／ 次 입 벌리고(欠) 머뭇대다 두(冫) 번째로 밀린 → 다음·순서

### 吹 (불 취)
구성: 口(입 · 뜻) + 欠(입 벌림 · 뜻)
유래: 뜻+뜻: 입을 벌려 숨을 불어 냄.
지금 외우기: 입 벌린 사람(欠)이 입(口)으로 촛불을 훅 → 불다
부품 이름: 欠 = **벌리다** ← 지금은 '사람' / 口 = 입


## 艮 = 그치다
이미 이 이름으로 쓰는 글자 7자. 예: 根 나무(木)의 흔들림을 그치게(艮) 땅속에서 꽉 붙드는 → 뿌리 ／ 銀 금 한 걸음 앞에서 그친(艮) 2등 쇠(金) → 은
다른 것으로 인정한 글자(그대로 둠): 밥그릇 郷即既 / 발길 退

### 墾 (개간할 간)
구성: 豸+艮(버틴 짐승 · 소리 コン) + 土(흙 · 뜻)
유래: 뜻+소리: 땅을 일구어 개간함.
지금 외우기: 짐승(豸)이 버티던(艮) 거친 흙(土)을 갈아엎는 → 일구다·개간하다
부품 이름: 豸 = 짐승 / 艮 = **그치다** ← 지금은 '버티던' / 土 = 흙


## 巾 = 천
이미 이 이름으로 쓰는 글자 11자. 예: 帳 천(巾)을 길게(長) 둘러친 → 장막·장부 ／ 席 잔칫집(广)에 스무(廿) 손님이 앉도록 깔아 둔 천(巾) 방석 → 자리

### 市 (저자 시)
구성: 亠(之가 바뀐 꼴 · 소리 シ) + 巾(冂은 시장의 담 · 뜻)
유래: 뜻+소리: 위의 亠는 之(シ)가 바뀐 꼴로 소리를 냄. 옛 사전에선 冂을 시장의 담으로 풀이함. '시장'.
지금 외우기: 담(巾)을 친 마당에 모자(亠) 쓴 장사꾼들이 북적이는 → 시장
부품 이름: 巾 = **천** ← 지금은 '담' [구성도 '冂은 시장의 담'] / 亠 = **지붕** ← 지금은 '모자'


## 礻 = 제단
이미 이 이름으로 쓰는 글자 6자. 예: 社 흙(土)의 신을 모신 제단(礻) 앞에 마을 사람들이 함께 뭉친 일터 → 모이다·회사 ／ 礼 제단(礻) 앞에서 허리(乙)를 깊이 굽혀 절하는 → 예의·인사
다른 것으로 인정한 글자(그대로 둠): 신 祈祉祥禅禍

### 視 (볼 시)
구성: 礻(보이다 · 소리 シ) + 見(보다 · 뜻)
유래: 뜻+소리: 똑바로 봄.
지금 외우기: 잘 보이게(礻) 내민 그림을 똑바로 보는(見) → 보다
부품 이름: 礻 = **제단** ← 지금은 '보이게' / 見 = 보다


## 夂 = 발
이미 이 이름으로 쓰는 글자 8자. 예: 麦 싹(龶)을 발(夂)로 밟아 키우는 → 보리 ／ 後 길(彳)에서 발(夂)이 끈(幺)에 묶여 꼴찌로 처진 → 뒤

### 条 (조목 조)
구성: 夂(攸의 攵이 변한 꼴 · 소리 ユウ) + 木(나무 · 뜻)
유래: 뜻+소리: 원래 글자 條는 木(나무)가 뜻, 攸(ユウ)가 소리. 나무의 잔가지. 일본에서는 亻·丨을 빼고 攵을 夂 꼴로 씀.
지금 외우기: 나무(木) 마디(夂)마다 잔가지가 번호 매긴 듯 하나씩 뻗은 → 가닥·조목
부품 이름: 木 = 나무 / 夂 = **발** ← 지금은 '마디'


## 丁 = 장정
이미 이 이름으로 쓰는 글자 6자. 예: 町 밭(田) 둑길 따라 젊은 일꾼(丁)들이 모여 사는 → 마을 ／ 打 장정(丁)이 손(扌)에 망치 쥐고 땅땅 → 치다
다른 것으로 인정한 글자(그대로 둠): 못 成可

### 寧 (편안할 녕)
구성: 寍(편안함 · 뜻·소리 ネイ) + 丁(丂이 바뀐 꼴)
유래: 뜻+소리: 寍(편안함, ネイ는 소리도 냄)+丁(본래 丂). 寍은 집(宀)에 마음(心)과 그릇(皿)이 있어 편안함.
지금 외우기: 집(宀) 밥상(丁)에 그릇(皿) 가득 밥을 보고 마음(心) 놓는 → 편안하다
부품 이름: 宀 = 집 / 丁 = **장정** ← 지금은 '밥상' / 皿 = 그릇 / 心 = 마음


## 弓 = 활
이미 이 이름으로 쓰는 글자 9자. 예: 引 활(弓) 옆 시위(丨)를 힘껏 → 끌다·당기다 ／ 弱 털(冫) 장식만 단 활(弓) 둘이 흐물흐물 휘는 → 약하다

### 弟 (아우 제)
구성: 丷+弓+丨+丿(감은 끈 · 모양)
유래: 그림: 막대에 끈을 차례대로 감은 모양에서 '차례', 뒤에 '아우'를 뜻함.
지금 외우기: 막대(丨)에 끈(弓)을 차례로 감듯 형 다음에 태어난 → 아우
부품 이름: 丨 = 막대 / 弓 = **활** ← 지금은 '끈'


## 卜 = 점
이미 이 이름으로 쓰는 글자 7자. 예: 外 저녁(夕)이면 점(卜)쟁이가 대문 너머 길가에 자리 펴는 → 바깥 ／ 占 점(卜)친 결과를 입(口)으로 술술 풀어 주는 → 점치다

### 上 (위 상)
구성: 卜(위에 그은 짧은 획 · 기호) + 一(기준선 · 기호)
유래: 기호: 기준선 위에 짧은 획을 그어 '위'를 가리킴.
지금 외우기: 기준선(一) 너머 하늘로 짧은 획(卜)이 쑥 솟아오른 → 위
부품 이름: 一 = 기준선 / 卜 = **점** ← 지금은 '획'


## 廾 = 두 손
이미 이 이름으로 쓰는 글자 5자. 예: 開 문(門)의 빗장(一)을 두 손(廾)으로 벗기니 → 열다 ／ 弁 나(厶)의 주장을 두 손(廾) 들어 펼치니 → 변론

### 冊 (책 책)
구성: 冂(바깥 대쪽 · 모양) + 廾(안쪽 대쪽과 끈 · 모양)
유래: 그림: 글을 적던 대나무 조각(대쪽)을 끈으로 엮어 묶은 모양을 그림.
지금 외우기: 대쪽(冂)들을 끈(廾)으로 가로질러 엮은 → 책
부품 이름: 冂 = **틀** ← 지금은 '대쪽' [구성도 '바깥 대쪽'] / 廾 = **두 손** ← 지금은 '끈'
