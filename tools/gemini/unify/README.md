# 외우기의 부품 이름 통일 (Gemini 앱에 맡김, 2026-11-16)

사용자 지적: 같은 부품을 글자마다 다른 것으로 부른다(厶: 私에서는 '나', 窓에서는 '코'; 占: 点에서는 '점치다', 店에서는 '점령하다').
사용자 결정: 부품마다 뜻을 하나로 통일한다. 작문은 Gemini가 한 명의 작가로서 하고, Claude는 검수(오류, 어색함, 구성·유래와 어긋남)를 맡는다.
길어지는 것은 괜찮다.

## 규모 (`make_request.py`가 출력)

| 항목 | 수 |
|---|---|
| 외우기가 `이름(모양)`으로 부품을 부른 곳(괄호 안 모양 하나) | 4,132곳, 모양 817가지 |
| 두 글자 이상이 쓰는 부품 | 495 |
| 그중 낱말이 둘 이상인 부품(활용형 포함) | 353 |
| 뜻이 실제로 갈린 부품(즉석 별명이 하나라도 있음) | 232 |
| 구성 줄이 보여 주는 '실제로 다른 것'을 인정한 부품(月 몸/달, 阝 언덕/고을 …) | 51 |
| **다시 쓸 외우기** | **353자** (2,136자의 17%) |
| ├ 반드시 바꿀 글자: 카드에 근거 없는 즉석 별명 | 153자 (`batch-01`, `batch-02`) |
| └ 구성 줄도 그 글자에서 그 이름을 쓰는 글자: 고정 이름으로 쓰거나 유지 | 200자 (`batch-03`~`batch-05`) |
| 이번에 뺀 그림 글자(부품 하나, 조각을 그림의 부분으로 부름) | 36자 |

바꿀 곳이 많은 부품: 一 16, 口 13, 丿 11, 十 9, 八 6, 丶 6, 田 6, 乙 5, 覀 5, 厶 5. 획과 작은 조각이 많다: 뜻이 없는 모양이라
글자마다 그림을 붙여 왔기 때문이다.

## 판정 (`groups.tsv`)

부품마다 고정 이름 하나와, 외우기가 쓰는 모든 낱말의 꼬리표.

- `S` 고정 이름과 같은 뜻: 활용형, 그 뜻을 품은 합성어, 같은 것으로 아는 말(물/강물, 치다/쳐서, 장정/일꾼, 가다/길).
- `I:이름` 실제로 다른 것: 그 글자들의 구성 줄이 그 이름을 보여 줄 때만(두 글자 이상, 또는 구성 이름이 `본래 …`, `…가 변한 꼴`).
- `N` 그 밖의 즉석 별명·소리 말장난: 다시 쓸 대상.

만든 방법: 353개 부품을 다섯 묶음으로 나눠 독립 판정자(같은 기준서)가 낱말마다 꼬리표를 붙이고, Claude가 전부 읽어 고쳤다.
고친 것: 辶·彳의 '길'은 '가다'와 같은 뜻, 殳는 `치다`(몽둥이 포함), 飠는 `먹다`(밥 포함), 획과 뜻 없는 조각의 이름을 정함
(丿 삐침, 亅 갈고리, 八·丷 나누다, ⺍ 불꽃, 冂 틀), 千 `천`, 壬 `짐`, 育 `기르다`, 이름이 괄호 뒤로 이어지는 곳(점(占)칠, 동(東)쪽,
합(合)치는)은 같은 뜻, 한 글자뿐인 I는 구성 이름에 `본래`·`변한 꼴`이 있을 때만.

판정은 모델이 한 것이라 틀린 곳이 있을 수 있다. Gemini는 이름표의 이름을 스스로 바꾸지 않고 `메모:`로 제안한다.

## 돌아온 답 처리 (아직 안 함)

1. 답을 `returned-NN.txt`로 저장, `python3 tools/gemini/unify/check_return.py returned-*.txt --accept`.
2. 검수: `✗`는 버리고, `△`는 읽고 판단. 통과한 줄도 전부 읽는다: 어색한 문장, 장면에서 뜻이 안 나옴, 끼워 넣은 부품,
   구성·유래와 어긋남. 작가의 문체를 고치지 않고, 문제가 있는 줄만 지금 줄로 둔다. `메모:`의 이름 제안을 모아 `groups.tsv`에 반영할지 정한다.
3. 받은 줄을 `tools/origin/kosei/link/link-unify.tsv`로 넣고 `merge.py`의 tail에 추가, `python3 tools/origin/merge.py`.
4. **길이 제한을 올린다**: 지금 50자(`PartsTest.shippedOrigins`, `link/ship_check.py`, `link/rules.py`의 `MEMO_MAX`)인데 지침은 70자까지 허용했다.
5. **구성 이름도 맞춘다**: 소리 부품의 훈음이 옛 외우기를 따라 글자마다 다른 곳(店의 占 `점령할 점`)을 고정 이름의 훈음으로.
6. 그림 글자 36자와, Gemini가 유지한 글자는 불일치로 남는다. 남은 수를 여기에 적는다.
