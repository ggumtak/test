# 부품 이름 통일 · batch-03 (89자, 구성 줄도 그 이름을 쓰는 글자: 고정 이름으로 자연스럽게 안 되면 '유지')

## 口 = 입
이미 이 이름으로 쓰는 글자 78자. 예: 口 '아~' 하고 네모나게 쩍 벌린 입(口) → 입 ／ 右 오른손(𠂇)으로 밥을 입(口)에 넣는 → 오른쪽
다른 것으로 인정한 글자(그대로 둠): 그릇 合豆器 / 창 高向

### 中 (가운데 중)
구성: 口(네모 판 · 모양) + 丨(깃대 · 모양)
유래: 그림: 깃대 가운데에 口 모양이 있고 깃발이 달린 모양. 무리 한가운데 세운 깃발에서 '가운데'(의견이 갈림).
지금 외우기: 깃대(丨)가 네모 판(口) 한복판을 꿰뚫은 → 가운데
부품 이름: 丨 = **막대** ← 지금은 '깃대' [구성도 '깃대'] / 口 = **입** ← 지금은 '판' [구성도 '네모 판']

### 石 (돌 석)
구성: 厂(벼랑 · 모양) + 口(돌덩이 · 모양)
유래: 그림: 厂(벼랑) 아래에 口(돌덩이)가 있는 모양임.
지금 외우기: 벼랑(厂) 밑에 굴러떨어진 돌덩이(口) → 돌
부품 이름: 厂 = 벼랑 / 口 = **입** ← 지금은 '돌덩이' [구성도 '돌덩이']

### 足 (발 족)
구성: 口(무릎 · 모양) + 龰(발 · 모양)
유래: 그림: 위는 무릎(口), 아래는 발(止)로 다리 전체를 그린 모양임.
지금 외우기: 무릎(口)부터 발(龰)까지 쭉 뻗은 → 발·다리
부품 이름: 口 = **입** ← 지금은 '무릎' [구성도 '무릎'] / 龰 = 발

### 員 (인원 원)
구성: 口(동그라미 ○ · 뜻) + 貝(돈 모양, 본래 솥 · 뜻)
유래: 뜻+뜻: 鼎(솥, 지금 貝 꼴) 위에 ○(口)를 그려 '둥글다'를 나타냄(圓의 원래 글자). 뒤에 사람 수.
지금 외우기: 솥(貝) 위 동그라미(口)처럼 빙 둘러앉은 식구 수 → 인원
부품 이름: 貝 = 솥 / 口 = **입** ← 지금은 '동그라미' [구성도 '동그라미 ○']

### 各 (각각 각)
구성: 夂(아래로 향한 발 · 뜻) + 口(집 입구 · 뜻)
유래: 뜻+뜻: 본래 '이르다', 뒤에 '각각'의 뜻으로 씀.
지금 외우기: 발(夂)길 닿는 집(口)마다 따로따로 도착하니 → 각각
부품 이름: 夂 = 발 / 口 = **입** ← 지금은 '집' [구성도 '집 입구']

### 束 (묶을 속)
구성: 木(나무 · 뜻) + 口(끈 · 뜻)
유래: 뜻+뜻: 나무를 끈으로 둘러 묶은 모양임.
지금 외우기: 나무(木) 가운데를 끈(口)으로 질끈 → 묶다
부품 이름: 木 = 나무 / 口 = **입** ← 지금은 '끈' [구성도 '끈']

### 倉 (창고 창)
구성: 人(지붕 · 모양) + 一+ヨ+丿(문 · 모양) + 口(바닥 · 모양)
유래: 그림: 지붕·문·바닥을 갖춘 곡식 창고 모양임.
지금 외우기: 지붕(人) 아래 문(一·ヨ·丿) 달고 바닥(口)에 곡식 쌓은 → 창고
부품 이름: 人 = 지붕 / 口 = **입** ← 지금은 '바닥' [구성도 '바닥']

### 串 (꿸 천)
구성: 口(꿴 물건 하나 · 모양) + 中(물건 하나와 꼬챙이 · 모양)
유래: 그림: 물건 두 개를 꼬챙이로 꿴 모양. 貫(꿰다)와 뜻이 통함.
지금 외우기: 꼬챙이 꽂힌 물건(中)에 물건 하나(口)를 더 꿰어 → 꼬치
부품 이름: 中 = **가운데** ← 지금은 '물건' [구성도 '물건 하나와 꼬챙이'] / 口 = **입** ← 지금은 '하나' [구성도 '꿴 물건 하나']


## 一 = 하나
이미 이 이름으로 쓰는 글자 8자. 예: 百 하나(一)같이 흰(白) 머리, 백 살 → 백 ／ 同 한(一) 지붕(冂) 아래 입(口) 모아 한목소리 내는 → 같다
다른 것으로 인정한 글자(그대로 둠): 기준선 上下 / 땅 土生立才止丘 / 성 正

### 天 (하늘 천)
구성: 一(강조한 큰 머리 · 기호) + 大(사람 · 모양)
유래: 기호: 大(사람) 위에 큰 머리를 강조한 모양. 본래 '정수리', 뒤에 '하늘'의 뜻으로 씀.
지금 외우기: 사람(大)의 큰 머리(一) 위로 탁 트인 → 하늘
부품 이름: 大 = 사람 / 一 = **하나** ← 지금은 '머리' [구성도 '강조한 큰 머리']

### 画 (그림 화)
구성: 一(붓 · 뜻) + 由(밭 · 뜻) + 凵(경계선 · 뜻)
유래: 뜻+뜻: 원래 글자 畫는 聿(붓)+田(밭)+경계선. 붓으로 밭 경계를 긋는 모양. 일본에서는 聿을 一로 줄여 씀.
지금 외우기: 붓(一)으로 밭(由) 둘레에 경계선(凵)을 쓱 긋는 → 그림·긋다
부품 이름: 一 = **하나** ← 지금은 '붓' [구성도 '붓'] / 由 = **지나다** ← 지금은 '밭' [구성도 '밭'] / 凵 = **구덩이** ← 지금은 '경계선' [구성도 '경계선']

### 丁 (장정 정)
구성: 一(못대가리 · 모양) + 亅(못의 몸 · 모양)
유래: 그림: 못(釘)의 모양으로, 지금 꼴은 一이 못대가리, 亅이 못의 몸. 뒤에 장정(젊은 일꾼), 순서를 매길 때 넷째인 '정' 등으로 빌려 쓰고, 못은 釘을 따로 만듦.
지금 외우기: 못대가리(一)부터 몸(亅)까지 꼿꼿한 못 같은 젊은 일꾼 → 장정
부품 이름: 一 = **하나** ← 지금은 '못대가리' [구성도 '못대가리'] / 亅 = **갈고리** ← 지금은 '몸' [구성도 '못의 몸']

### 開 (열 개)
구성: 門(문 · 뜻) + 一(빗장 · 뜻) + 廾(두 손 · 뜻)
유래: 뜻+뜻: 문(門)에 걸린 가로 빗장(一)을 두 손(廾)으로 들어 벗겨 문을 엶을 나타냄.
지금 외우기: 문(門)의 빗장(一)을 두 손(廾)으로 벗기니 → 열다
부품 이름: 門 = 문 / 一 = **하나** ← 지금은 '빗장' [구성도 '빗장'] / 廾 = 두 손

### 夫 (남편 부)
구성: 一(비녀 · 모양) + 大(사람 · 모양)
유래: 그림: 大(사람) 머리에 비녀(一)를 꽂은 성인 남자 모양임.
지금 외우기: 사람(大) 머리에 비녀(一)를 꽂은 어른 남자 → 남편
부품 이름: 大 = 사람 / 一 = **하나** ← 지금은 '비녀' [구성도 '비녀']

### 末 (끝 말)
구성: 一(끝 줄 · 기호) + 木(나무 · 모양)
유래: 기호: 木(나무) 위쪽에 획(一)을 그어 나무 끝을 가리킴.
지금 외우기: 나무(木) 꼭대기에 긴 줄(一) → 끝
부품 이름: 木 = 나무 / 一 = **하나** ← 지금은 '줄' [구성도 '끝 줄']

### 旦 (아침 단)
구성: 日(해 · 모양) + 一(지평선 · 기호)
유래: 기호: 해(日)가 지평선(一) 위로 떠오르는 모양임.
지금 외우기: 해(日)가 지평선(一) 위로 → 아침
부품 이름: 日 = 해 / 一 = **하나** ← 지금은 '지평선' [구성도 '지평선']


## 十 = 열
이미 이 이름으로 쓰는 글자 10자. 예: 古 열(十) 세대의 입(口)을 거쳐 전해 내려온 → 옛날 ／ 米 십(十)자 둘레에 흩어진 낟알 넷 → 쌀

### 直 (곧을 직)
구성: 十(눈 위의 곧은 선 · 뜻) + 目(눈 · 뜻) + 乚(뒤에 더해진 ㄴ 꼴)
유래: 뜻+뜻: 目(눈) 위에 곧은 선(丨, 지금은 十 꼴)을 그어 똑바로 봄을 나타냄. 뒤에 아래 ㄴ 꼴이 더해짐.
지금 외우기: 눈(目) 위에 곧은 선(十)을 대고 똑바로 겨누는 → 곧다
부품 이름: 目 = 눈 / 十 = **열** ← 지금은 '선' [구성도 '눈 위의 곧은 선']

### 章 (글 장)
구성: 音(음악 · 뜻) + 十(마침 · 뜻)
유래: 뜻+뜻: 옛 사전은 音(음악)+十(마침)으로 '음악 한 단락'이라 풂. 옛 청동기 글자의 풀이는 의견이 갈림.
지금 외우기: 음악(音) 한 대목 끝에 마침(十)표를 콕 찍은 → 장·단락
부품 이름: 音 = **소리** ← 지금은 '음악' [구성도 '음악'] / 十 = **열** ← 지금은 '마침' [구성도 '마침']

### 協 (도울 협)
구성: 十(많음 · 뜻) + 劦(모은 힘 · 뜻·소리 キョウ)
유래: 뜻+소리: 여럿이 힘을 모음.
지금 외우기: 많은(十) 사람이 힘(劦)을 합쳐 영차영차 → 협력하다
부품 이름: 十 = **열** ← 지금은 '많은' [구성도 '많음'] / 劦 = 힘

### 博 (넓을 박)
구성: 十(사방 · 뜻) + 尃(펴다 · 뜻·소리 フ)
유래: 뜻+소리: 널리 펴서 두루 통함.
지금 외우기: 사방(十)으로 지식을 널리 펴는(尃) → 넓다·박사
부품 이름: 十 = **열** ← 지금은 '사방' [구성도 '사방'] / 尃 = 펴다

### 支 (지탱할 지)
구성: 十(대나무 가지 하나 · 뜻) + 又(손 · 뜻)
유래: 뜻+뜻: 又(손)에 대나무 가지 하나(十)를 든 모양(옛 사전 풀이). 본래 '가지', 뒤에 버티다·갈라지다.
지금 외우기: 손(又)에 쥔 대나무 가지(十)로 받치는 → 지탱하다
부품 이름: 又 = 손 / 十 = **열** ← 지금은 '가지' [구성도 '대나무 가지 하나']

### 針 (바늘 침)
구성: 金(쇠 · 뜻) + 十(바늘 · 뜻)
유래: 뜻+뜻: 金(쇠)+十(바늘 모양이라 봄, 의견이 갈림). 쇠바늘. 鍼(침)과 모양만 다른 같은 글자.
지금 외우기: 쇠(金)바늘(十)에 실을 꿰어 한 땀 한 땀 → 바늘
부품 이름: 金 = 쇠 / 十 = **열** ← 지금은 '바늘' [구성도 '바늘']


## 田 = 밭
이미 이 이름으로 쓰는 글자 17자. 예: 男 밭(田)에서 쟁기(力)를 끄는 사람 → 사내·남자 ／ 町 밭(田) 둑길 따라 젊은 일꾼(丁)들이 모여 사는 → 마을
다른 것으로 인정한 글자(그대로 둠): 머리 思異畏

### 魚 (물고기 어)
구성: 𠂊(머리 · 모양) + 田(몸통 · 모양) + 灬(꼬리 · 모양)
유래: 그림: 머리·비늘 있는 몸통·꼬리를 갖춘 물고기 모양. 아래 灬는 본래 꼬리를 뜻함.
지금 외우기: 머리(𠂊)부터 비늘 몸통(田)과 꼬리(灬)까지 파닥파닥 → 물고기
부품 이름: 𠂊 = **사람** ← 지금은 '머리' [구성도 '머리'] / 田 = **밭** ← 지금은 '몸통' [구성도 '몸통'] / 灬 = **불** ← 지금은 '꼬리' [구성도 '꼬리']

### 果 (실과 과)
구성: 田(열매 · 모양) + 木(나무 · 모양)
유래: 그림: 나무(木) 위에 열매(田 꼴)가 달린 모양. 뒤에 결과를 뜻함.
지금 외우기: 꽃 진 자리 나무(木) 위에 열매(田)가 맺힌 → 열매·결과
부품 이름: 木 = 나무 / 田 = **밭** ← 지금은 '열매' [구성도 '열매']

### 胃 (밥통 위)
구성: 田(음식이 든 위장 · 모양) + 月(몸 · 뜻)
유래: 그림: 田 꼴은 음식이 든 위장 모양, 月(⺼, 몸)을 더함.
지금 외우기: 음식이 칸칸이 찬 위장(田)을 품은 몸(月) → 위
부품 이름: 田 = **밭** ← 지금은 '위장' [구성도 '음식이 든 위장'] / 月 = 몸

### 巣 (새집 소)
구성: ⺍(새끼 새 · 모양) + 田(둥지 · 모양) + 木(나무 · 모양)
유래: 그림: 원래 글자 巢는 나무(木) 위 둥지에 새(巛)가 있는 모양. 일본에서는 巛을 ⺍로 줄여 씀.
지금 외우기: 나무(木) 위 둥지(田)에서 새끼 새(⺍)들이 삐약대는 → 둥지
부품 이름: 木 = 나무 / 田 = **밭** ← 지금은 '둥지' [구성도 '둥지'] / ⺍ = **불꽃** ← 지금은 '새' [구성도 '새끼 새']

### 雷 (우레 뢰)
구성: 雨(비 · 뜻) + 田(천둥 · 뜻·소리 ライ)
유래: 뜻+소리: 雨(비)가 뜻, 田은 畾(ライ)가 줄어든 꼴로 소리도 내고 뜻도 보탬. 畾는 천둥을 동그라미로 그린 것.
지금 외우기: 비(雨) 구름 속에서 천둥(田)이 우르릉 쾅쾅 → 천둥
부품 이름: 雨 = 비 / 田 = **밭** ← 지금은 '천둥' [구성도 '천둥']


## 丶 = 점
이미 이 이름으로 쓰는 글자 6자. 예: 玉 끈에 꿴 옥구슬(王) 옆에 반짝이는 점(丶) 하나 → 구슬 ／ 丸 반죽을 아홉(九) 번 굴려 점(丶)처럼 동글게 빚은 → 둥글다

### 州 (고을 주)
구성: 丶(모래섬 · 모양) + 川(물 · 모양) + 丶(모래섬 · 모양) + 丶(모래섬 · 모양)
유래: 그림: 물(川) 가운데 모래섬(점)이 있는 모양. 洲의 원래 글자, 뒤에 행정구역을 뜻함.
지금 외우기: 냇물(川) 사이사이 모래섬(丶)마다 마을이 선 → 고을·주
부품 이름: 川 = 냇물 / 丶 = **점** ← 지금은 '모래섬' [구성도 '모래섬']

### 以 (써 이)
구성: レ+丶(쟁기 · 뜻) + 人(사람 · 뜻)
유래: 뜻+뜻: 㠯(쟁기 같은 도구로 봄)+人(사람). 도구를 써서 일함에서 '~로써'(의견이 갈림).

부품 이름: 人 = 사람 / 丶 = **점** ← 지금은 '쟁기' [구성도 '쟁기']

### 丹 (붉을 단)
구성: 冂(구덩이 · 모양) + 丶(붉은 알갱이 · 모양) + 一(구덩이의 일부 · 모양)
유래: 그림: 붉은 광물(단사)을 캐는 구덩이(冂) 속 붉은 알갱이(丶)를 그림. 一은 구덩이의 일부를 뜻함.

부품 이름: 丶 = **점** ← 지금은 '알갱이' [구성도 '붉은 알갱이']

### 丼 (덮밥 정)
구성: 井(우물 · 모양) + 丶(두레박 · 모양)
유래: 그림: 우물(井) 가운데 두레박(丶)을 그린 井의 옛 꼴. 덮밥(どんぶり)은 일본에서 붙인 뜻을 뜻함.
지금 외우기: 우물(井)에 두레박(丶) 빠지듯 깊은 사발에 밥이 퐁 → 덮밥
부품 이름: 井 = 우물 / 丶 = **점** ← 지금은 '두레박' [구성도 '두레박']


## 白 = 희다

### 泉 (샘 천)

### 皇 (임금 황)

부품 이름: 白 = **희다** ← 지금은 '관' [구성도 '장식 달린 관이라 봄'] / 王 = 임금

### 皆 (다 개)

부품 이름: 比 = **나란하다** ← 지금은 '사람들' [구성도 '선 사람'] / 白 = **희다** ← 지금은 '말하는' [구성도 '말하다']

## 乙 = 굽다
이미 이 이름으로 쓰는 글자 2자. 예: 乳 손(爫)으로 아이(子)를 안아 굽은(乙) 품에 대고 먹이는 → 젖 ／ 乞 고개(𠂉) 숙이고 허리 굽혀(乙) 손 내미는 → 구걸하다

### 乱 (어지러울 란)

### 孔 (구멍 공)

### 乾 (마를 건)
구성: 十+早+𠂉(倝이 변한 꼴 · 소리 カン) + 乙(위로 솟음 · 뜻)

지금 외우기: 아침 해(十·早)가 높이 솟아(乙) 쨍쨍 → 마르다
부품 이름: 乙 = **굽다** ← 지금은 '솟아' [구성도 '위로 솟음']


## ⺍ = 불꽃
이미 이 이름으로 쓰는 글자 2자. 예: 労 횃불(⺍) 밝힌 덮개(冖) 아래서 밤새 힘(力)을 쏟는 → 일하다 ／ 栄 불꽃(⺍) 같은 꽃이 지붕(冖)처럼 나무(木)를 덮은 → 번영

### 学 (배울 학)

부품 이름: 月 = 몸 / ⺍ = **불꽃** ← 지금은 '머리털' [구성도 '머리털'] / 凶 = 정수리(이 글자에만 있는 부품: 그대로)

## 覀 = 덮개

## 韋 = 가죽

## 艹 = 풀

## 日 = 해
이미 이 이름으로 쓰는 글자 35자. 예: 白 해(日) 위로 빛줄기(丿) 하나, 환한 → 희다 ／ 早 해(日)가 십자(十) 탑 위로 막 떠오른 아침 → 이르다

부품 이름: 立 = **서다** ← 지금은 '말' [구성도 '말'] / 日 = **해** ← 지금은 '입' [구성도 '울림 입']

### 冒 (무릅쓸 모)

## 乂 = 엇갈리다
이미 이 이름으로 쓰는 글자 1자. 예: 殺 나무(木)에 엇갈려(乂) 묶고 몽둥이(殳)로 내리치는 → 죽이다
다른 것으로 인정한 글자(그대로 둠): 물건 区

### 希 (바랄 희)
구성: 乂(엇갈린 실 · 뜻) + 布(베 · 뜻)
유래: 뜻+뜻: 乂(엇갈린 실)+巾(천)으로 봄. 본래 '드물다', 뒤에 '바라다'(유래는 의견이 갈림).
지금 외우기: 성긴 베(布)에 엇갈린 실(乂)로 소원을 수놓으며 고대하는 → 바라다
부품 이름: 布 = 베 / 乂 = **엇갈리다** ← 지금은 '실' [구성도 '엇갈린 실']

### 刈 (벨 예)
구성: 乂(풀 베다 · 뜻·소리 ガイ) + 刂(칼 · 뜻)
유래: 뜻+소리: 乂에 刂를 더해 '베다'를 분명히 함.
지금 외우기: 풀을 쓱쓱 베고(乂) 칼(刂)로 또 싹둑 → 베다
부품 이름: 乂 = **엇갈리다** ← 지금은 '베고' [구성도 '풀 베다'] / 刂 = 칼


## 里 = 마을
이미 이 이름으로 쓰는 글자 6자. 예: 理 구슬(王)을 마을(里) 장인이 결 따라 깎는 → 이치 ／ 野 마을(里) 밖에 소를 미리(予) 풀어 둔 넓은 → 들판

### 黒 (검을 흑)
구성: 里(굴뚝 · 뜻) + 灬(불 · 뜻)
유래: 뜻+뜻: 옛 사전은 원래 글자 黑을 굴뚝(囪)과 불(炎)로 그을음 빛을 나타낸다고 풂. 가장 오래된 모양의 풀이는 의견이 갈림.
지금 외우기: 불(灬) 위 굴뚝(里)이 그을음에 새까맣게 → 검다
부품 이름: 灬 = 불 / 里 = **마을** ← 지금은 '굴뚝' [구성도 '굴뚝']

### 量 (양 량)
구성: 旦(주둥이 · 뜻) + 里(자루 · 뜻)
유래: 뜻+뜻: 가장 오래된 모양은 자루(東) 위에 주둥이(日)를 그려, 곡식을 자루에 담아 되로 잼을 나타냄. 아래가 里 꼴로 변함(의견이 갈림).
지금 외우기: 자루(里) 위 주둥이(旦)로 곡식을 되로 재어 붓는 → 양·재다
부품 이름: 里 = **마을** ← 지금은 '자루' [구성도 '자루'] / 旦 = **아침** ← 지금은 '주둥이' [구성도 '주둥이']


## 丷 = 나누다
이미 이 이름으로 쓰는 글자 1자. 예: 半 큰 소(一·十)를 머리부터 꼬리까지 둘로 나눈(丷) → 반

### 従 (좇을 종)
구성: 彳(가다 · 뜻) + 丷(두 사람 · 뜻·소리 ジュウ) + 疋(발 · 뜻)
유래: 뜻+소리: 원래 글자 從은 辵(가다, 彳과 오른쪽 아래 止 꼴)+从(사람이 사람을 따름). 从은 소리도 내고 뜻도 보탬. 일본에서는 从을 丷 꼴로 줄여 씀.
지금 외우기: 두 사람(丷)이 앞뒤로 발(疋)맞춰 졸졸 가는(彳) → 따르다
부품 이름: 丷 = **나누다** ← 지금은 '사람' [구성도 '두 사람'] / 疋 = 발 / 彳 = 가다

### 曽 (일찍 증)
구성: 丷(오르는 김 · 모양) + 田+日(시루 · 모양)
유래: 그림: 원래 글자 曾은 시루(甑, 찌는 그릇)에서 김이 오르는 모양. '일찍이·거듭'은 소리만 빌려 씀. 일본에서는 八을 ソ로 쓰는 등 획을 줄임.
지금 외우기: 내가 태어나기도 전부터 김(丷) 뿜던 할머니의 시루(田日) → 일찍이
부품 이름: 丷 = **나누다** ← 지금은 '김' [구성도 '오르는 김']


## 正 = 바르다
이미 이 이름으로 쓰는 글자 5자. 예: 整 종이를 묶고(束) 탁탁 쳐(攵) 바르게(正) → 가지런히 하다 ／ 政 탐관오리는 매로 치고(攵) 굽은 일은 바르게(正) 펴는 나랏일 → 정치

### 延 (늘일 연)
구성: 正(발 · 뜻) + 廴(길게 걷다 · 뜻)
유래: 뜻+뜻: 廴(길게 걷다)+止(발)에 丿을 더해(지금은 正 꼴) 멀리 길게 감을 나타냄(의견이 갈림).
지금 외우기: 발(正)을 질질 끌며 길게 걸어가는(廴) → 늘이다
부품 이름: 正 = **바르다** ← 지금은 '발' [구성도 '발'] / 廴 = 걷다

### 卸 (도매 사)
구성: 午(낮 오) + 正(멈추다) + 卩(꿇은 사람)
유래: 뜻+뜻: 午·止·卩로 이루어짐. 옛 사전은 수레를 멈추고 말을 풀어 놓음이라 함. 일본에선 도매.
지금 외우기: 한낮(午) 장터에 수레 멈추고(正) 꿇어앉아(卩) 짐을 통째 넘기는 → 도매
부품 이름: 午 = 낮 / 正 = **바르다** ← 지금은 '멈추고' [구성도 '멈추다'] / 卩 = 꿇은 사람


## 共 = 함께
이미 이 이름으로 쓰는 글자 3자. 예: 洪 물(氵)이 함께(共) 한꺼번에 밀려오는 → 홍수 ／ 恭 두 손 모아 함께(共) 받드는 마음(⺗) → 공손

### 供 (이바지할 공)
구성: 亻(사람 · 뜻) + 共(두 손으로 받듦 · 뜻·소리 キョウ)
유래: 뜻+소리: 사람이 물건을 받들어 바침.
지금 외우기: 사람(亻)이 음식을 두 손으로 받들어(共) 올리는 → 바치다·이바지하다
부품 이름: 亻 = 사람 / 共 = **함께** ← 지금은 '받들어' [구성도 '두 손으로 받듦']

### 異 (다를 이)
구성: 田(탈 쓴 머리 · 모양) + 共(두 손 든 몸 · 모양)
유래: 그림: 머리에 무언가(탈)를 쓰고 두 손을 든 사람 모양(의견이 갈림). 뒤에 '다르다'의 뜻.
지금 외우기: 탈 쓴 머리(田)에 두 손 든 몸(共)이 딴사람 같은 → 다르다
부품 이름: 田 = 머리 / 共 = **함께** ← 지금은 '몸' [구성도 '두 손 든 몸']


## 廿 = 스물
이미 이 이름으로 쓰는 글자 3자. 예: 度 집(广)에서 손(又)으로 스무(廿) 번이나 재 보는 → 정도·번 ／ 席 잔칫집(广)에 스무(廿) 손님이 앉도록 깔아 둔 천(巾) 방석 → 자리

### 昔 (옛 석)
구성: 廿(물결 · 뜻) + 日(날 · 뜻)
유래: 뜻+뜻: 가장 오래된 글자는 물결 꼴+日(날). 홍수 났던 날로 '옛날'을 나타냈다고 보기도 함(의견이 갈림).
지금 외우기: 큰 물결(廿)이 마을을 덮쳤던 그날(日) → 옛날
부품 이름: 廿 = **스물** ← 지금은 '물결' [구성도 '물결'] / 日 = 날

### 共 (함께 공)
구성: 廿(물건 · 뜻) + 八(두 손 · 뜻)
유래: 뜻+뜻: 두 손(廾)으로 물건을 함께 받쳐 든 모양.
지금 외우기: 무거운 물건(廿)을 아래 두 손(八)으로 힘을 합쳐 드는 → 함께
부품 이름: 廿 = **스물** ← 지금은 '물건' [구성도 '물건'] / 八 = 손


## 几 = 받침대
이미 이 이름으로 쓰는 글자 2자. 예: 机 나무(木) 받침(几)에 팔꿈치 괴고 글 읽는 → 책상 ／ 肌 기대는 받침(几)에 맨살(月)이 닿는 겉 → 살갗

### 処 (처리할 처)
구성: 夂(발 · 뜻) + 几(걸상 · 뜻)
유래: 뜻+뜻: 걸음을 멈추고 걸상에 앉아 머묾. 원래 글자 處는 虍(コ)을 소리로 더한 꼴임.
지금 외우기: 걷던 발(夂)을 멈추고 걸상(几)에 앉아 일을 보는 → 처리하다·곳
부품 이름: 夂 = 발 / 几 = **받침대** ← 지금은 '걸상' [구성도 '걸상']

### 冗 (쓸데없을 용)
구성: 冖(집 · 뜻) + 几(사람 · 뜻)
유래: 뜻+뜻: 본래 宂으로 宀(집)+儿(사람), 지금은 冖+几 꼴. 집에서 일 없이 노는 사람, 곧 한가함에서 쓸데없음.
지금 외우기: 집(冖) 안에서 사람(几)이 하는 일 없이 빈둥빈둥 → 쓸데없다
부품 이름: 冖 = 집 / 几 = **받침대** ← 지금은 '사람' [구성도 '사람']
