# 부품 이름 통일 · batch-04 (90자, 구성 줄도 그 이름을 쓰는 글자: 고정 이름으로 자연스럽게 안 되면 '유지')

## 支 = 지탱하다
이미 이 이름으로 쓰는 글자 2자. 예: 技 손(扌) 하나로 장대를 지탱하며(支) 묘기 부리는 → 재주·기술 ／ 伎 사람(亻)이 장대로 몸을 지탱하며(支) 묘기 부리는 → 재주·가부키
다른 것으로 인정한 글자(그대로 둠): 갈라지다 岐肢

### 枝 (가지 지)
구성: 木(나무 · 뜻) + 支(가지 · 뜻·소리 シ)
유래: 뜻+소리: 支가 '지탱하다'로 쓰이자 木을 더함.
지금 외우기: 나무(木) 줄기에서 옆으로 뻗어 나온 가지(支) → 가지
부품 이름: 木 = 나무 / 支 = **지탱하다** ← 지금은 '가지' [구성도 '가지']

### 鼓 (북 고)
구성: 壴(세워 놓은 북 · 뜻) + 支(채를 든 손 · 뜻)
유래: 뜻+뜻: 북을 침, 북을 뜻함.
지금 외우기: 세운 북(壴)을 채 든 손(支)이 둥둥 → 북
부품 이름: 壴 = 북(이 글자에만 있는 부품: 그대로) / 支 = **지탱하다** ← 지금은 '손' [구성도 '채를 든 손']


## 林 = 숲
이미 이 이름으로 쓰는 글자 4자. 예: 歴 언덕(厂) 아래 숲(林)을 발(止)로 지나온 길 → 지나다·역사 ／ 禁 숲(林) 속 제단(示)엔 들어가지 마라 → 금지

### 森 (수풀 삼)
구성: 木(나무 · 뜻) + 林(나무 둘 · 뜻)
유래: 뜻+뜻: 木(나무) 셋을 겹쳐 나무가 빽빽한 '숲'을 나타냄.
지금 외우기: 나무(木) 아래 나무 둘(林)이 더 붙어 빽빽한 → 숲
부품 이름: 木 = 나무 / 林 = **숲** ← 지금은 '둘' [구성도 '나무 둘']

### 麻 (삼 마)
구성: 广(집 · 뜻) + 林(삼 껍질 · 뜻)
유래: 뜻+뜻: 작업장 지붕(广) 아래서 벗겨 낸 삼 줄기 껍질(林 꼴, 숲이 아님)을 손질함을 나타냄.
지금 외우기: 집(广) 처마 밑에 벗긴 삼 껍질(林)을 주렁주렁 말리는 → 삼
부품 이름: 广 = 집 / 林 = **숲** ← 지금은 '껍질' [구성도 '삼 껍질']


## 𡗗 = 손
이미 이 이름으로 쓰는 글자 1자. 예: 泰 큰 사람이 두 손(𡗗)으로 물(氺)을 끼얹으며 느긋이 → 편안하다

### 春 (봄 춘)
구성: 𡗗(돋는 풀 · 뜻·소리 トン) + 日(해 · 뜻)
유래: 뜻+소리: 본래 艸(풀)+日(해)가 뜻, 屯(トン)이 소리. 햇볕에 풀이 돋는 '봄'. 윗부분은 艸와 屯이 합쳐진 꼴임.
지금 외우기: 따뜻한 해(日)에 풀(𡗗)이 파릇파릇 돋는 → 봄
부품 이름: 日 = 해 / 𡗗 = **손** ← 지금은 '풀' [구성도 '돋는 풀']

### 実 (열매 실)
구성: 宀(집 · 뜻) + 𡗗(꿴 돈 · 뜻)
유래: 뜻+뜻: 원래 글자는 實. 집(宀) 안에 재물이 가득 차 알차다는 뜻에서 '열매·실제'가 됨.
지금 외우기: 집(宀) 안에 꿴 돈(𡗗)이 알차게 가득 찬 → 열매·실제
부품 이름: 宀 = 집 / 𡗗 = **손** ← 지금은 '돈' [구성도 '꿴 돈']


## 才 = 재주
이미 이 이름으로 쓰는 글자 1자. 예: 財 재주(才)를 부려 차곡차곡 모은 돈(貝) → 재물·재산

### 材 (재목 재)
구성: 木(나무 · 뜻) + 才(바탕 · 뜻·소리 サイ)
유래: 뜻+소리: 才는 '바탕'이라는 뜻도 보탬. 쓸모 있는 재목을 뜻함.
지금 외우기: 집 짓는 바탕(才)으로 골라 둔 나무(木) → 재목·재료
부품 이름: 才 = **재주** ← 지금은 '바탕' [구성도 '바탕'] / 木 = 나무

### 閉 (닫을 폐)
구성: 門(문 · 뜻) + 才(빗장 · 뜻)
유래: 뜻+뜻: 문에 빗장을 질러 닫음.
지금 외우기: 문(門) 안쪽에 빗장(才)을 척 질러 → 닫다
부품 이름: 門 = 문 / 才 = **재주** ← 지금은 '빗장' [구성도 '빗장']


## 月 = 몸
이미 이 이름으로 쓰는 글자 49자. 예: 有 손(𠂇)에 고기(月) 한 덩이를 꽉 쥐고 있는 → 있다 ／ 育 거꾸로 나온 아이(亠厶)를 엄마 몸(月)에 품어 → 기르다
다른 것으로 인정한 글자(그대로 둠): 배 前服朕 / 달 夕明朝勝期望朗惰覇

### 青 (푸를 청)
구성: 龶(새싹 · 소리 セイ) + 月(물감 · 뜻)
유래: 뜻+소리: 위 龶(본래 生, セイ)가 소리, 아래 丹(광물 물감)이 뜻. 광석에서 얻는 푸른 물감. 일본 글자는 丹을 月로 씀.
지금 외우기: 새싹(龶) 빛깔 물감(月)으로 칠한 → 푸르다
부품 이름: 龶 = 싹 / 月 = **몸** ← 지금은 '물감' [구성도 '물감']


## 土 = 흙
이미 이 이름으로 쓰는 글자 58자. 예: 金 지붕(人) 아래 흙(土) 속 반짝이는 알(丷) → 금·쇠 ／ 地 흙(土)이 구불구불(也) 끝없이 이어진 → 땅
다른 것으로 인정한 글자(그대로 둠): 사람 去 / 휘두르다 走

### 至 (이를 지)
구성: 一+厶(화살 · 모양) + 土(꽂힌 땅 · 기호)
유래: 기호: 화살이 날아와 땅(一)에 꽂힌 모양으로 '이르다'를 나타냄.
지금 외우기: 날아온 화살(一厶)이 땅에 푹 꽂힌(土) → 이르다
부품 이름: 土 = **흙** ← 지금은 '꽂힌' [구성도 '꽂힌 땅']


## 心 = 마음
이미 이 이름으로 쓰는 글자 46자. 예: 思 정수리(田)에 김 나도록 마음(心)까지 끙끙 → 생각하다 ／ 急 사람(𠂊)을 손(⺕)으로 붙잡으려 마음(心)이 → 급하다

### 芯 (심지 심)
구성: 艹(풀 · 뜻) + 心(가운데 · 뜻·소리 シン)
유래: 뜻+소리: 본래 등심초라는 풀, 그 속살로 등잔 심지를 만듦.
지금 외우기: 풀(艹) 줄기 한가운데(心) 속살을 뽑아 등잔에 꽂은 → 심지
부품 이름: 艹 = 풀 / 心 = **마음** ← 지금은 '한가운데' [구성도 '가운데']


## 貝 = 돈
이미 이 이름으로 쓰는 글자 33자. 예: 買 그물(罒) 가방에 돈(貝)을 넣고 장 보러 → 사다 ／ 負 사람(𠂊)이 돈(貝) 보따리를 등에 짊어진 → 지다
다른 것으로 인정한 글자(그대로 둠): 솥 員則貞 / 조개 唄鎖

### 賛 (도울 찬)
구성: 夫+夫(나아가다 兟을 바꿔 쓴 꼴 · 뜻) + 貝(예물 · 뜻)
유래: 뜻+뜻: 원래 글자 贊은 兟(나아가다)+貝(예물). 예물을 들고 나아가 뵘(옛 사전 풀이) → 돕다. 일본에서는 윗부분을 夫夫로 씀.
지금 외우기: 두 사내(夫夫)가 예물(貝)을 들고 나아가 힘을 보태는 → 돕다·찬성
부품 이름: 貝 = **돈** ← 지금은 '예물' [구성도 '예물']


## 宀 = 집
이미 이 이름으로 쓰는 글자 37자. 예: 字 집(宀)에서 아이(子)가 익히는 → 글자 ／ 室 집(宀)에 이르러(至) 들어가는 → 방

### 審 (살필 심)
구성: 宀(덮다 · 뜻) + 番(가려 나눔 · 뜻)
유래: 뜻+뜻: 본래 宷(宀+釆). 옛 사전은 宀(덮다)+釆(가려 나누다)로, 덮인 것을 가려 자세히 살핀다고 풂(의견이 갈림). 뒤에 釆이 番 꼴로 바뀜.
지금 외우기: 덮인(宀) 것을 걷어 하나하나 가려 나누는(番) → 살피다
부품 이름: 宀 = **집** ← 지금은 '덮인' [구성도 '덮다'] / 番 = **차례** ← 지금은 '나누는' [구성도 '가려 나눔']


## 禾 = 벼
이미 이 이름으로 쓰는 글자 27자. 예: 秋 벼(禾)가 불(火)처럼 붉게 익는 → 가을 ／ 科 벼(禾)를 말(斗)로 재어 등급별로 나눈 → 과목

### 稽 (상고할 계)
구성: 禾(굽은 나무 · 뜻) + 尤(더욱 우 · 뜻) + 旨(맛있을 지 · 소리 シ)
유래: 뜻+소리: 禾 꼴(벼가 아니라 '굽은 나무 계'라는 다른 글자)·尤가 뜻, 旨(シ)가 소리(옛 중국 사전의 풀이). 본래 머무름, 뒤에 따져 생각함.
지금 외우기: 굽은 나무(禾) 아래 머물러 맛(旨)을 더욱(尤) 곱씹는 → 생각하다
부품 이름: 禾 = **벼** ← 지금은 '나무' [구성도 '굽은 나무'] / 旨 = 맛있다 / 尤 = 더욱


## 攵 = 치다
이미 이 이름으로 쓰는 글자 24자. 예: 教 아이(子)에게 회초리로 쳐(攵)가며 글을 → 가르치다 ／ 数 여자(女)가 쌀(米)알을 톡톡 치며(攵) 하나하나 → 세다

### 致 (이를 치)
구성: 至(이르다 · 뜻·소리 シ) + 攵(걸음 · 뜻)
유래: 뜻+소리: 보내어 이르게 함.
지금 외우기: 걸음(攵)을 재촉해 끝까지 이르도록(至) → 이르게 하다
부품 이름: 攵 = **치다** ← 지금은 '걸음' [구성도 '걸음'] / 至 = 이르다


## 王 = 구슬
이미 이 이름으로 쓰는 글자 15자. 예: 玉 끈에 꿴 옥구슬(王) 옆에 반짝이는 점(丶) 하나 → 구슬 ／ 理 구슬(王)을 마을(里) 장인이 결 따라 깎는 → 이치
다른 것으로 인정한 글자(그대로 둠): 임금 皇呈狂旺 / 사람 望聖徴

### 主 (주인 주)
구성: 丶(불꽃 · 모양) + 王(등잔 · 모양)
유래: 그림: 등잔(王 꼴) 위에 불꽃(丶)이 타는 모양. 뒤에 '주인'의 뜻으로 쓰여 불꽃은 炷로 씀.
지금 외우기: 등잔(王) 위 불꽃(丶)처럼 집안 한가운데를 지키는 → 주인
부품 이름: 王 = **구슬** ← 지금은 '등잔' [구성도 '등잔'] / 丶 = **점** ← 지금은 '불꽃' [구성도 '불꽃']


## 寸 = 손
이미 이 이름으로 쓰는 글자 19자. 예: 寺 흙(土) 마당을 쓸고 손(寸) 모아 합장하는 곳 → 절 ／ 守 집(宀) 문을 손(寸)으로 꽉 붙들고 버티는 → 지키다
다른 것으로 인정한 글자(그대로 둠): 마디 村寿酎

### 耐 (견딜 내)
구성: 而(수염 · 뜻·소리 タイ) + 寸(법도 · 뜻)
유래: 뜻+소리: 수염만 깎는 가벼운 형벌(耏와 모양만 다른 같은 글자), 뒤에 '견디다'를 뜻함.
지금 외우기: 법(寸)대로 수염(而)을 깎이는 벌도 꾹 → 견디다
부품 이름: 寸 = **손** ← 지금은 '법' [구성도 '법도'] / 而 = 수염


## 广 = 집
이미 이 이름으로 쓰는 글자 20자. 예: 広 지붕(广) 아래 나(厶) 혼자 쓰니 → 넓다 ／ 店 지붕(广) 아래 한 자리를 점령해(占) 물건 파는 → 가게

### 慶 (경사 경)
구성: 广(사슴 · 뜻) + 心(마음 · 뜻) + 夂(발 · 뜻)
유래: 뜻+뜻: 广(사슴 鹿에서 比를 뺀 꼴)+心(마음)+夂(가다). 옛 중국 사전에서는 사슴 가죽을 선물로 들고 축하하러 감이라 함.
지금 외우기: 사슴(广) 가죽에 마음(心) 담아 발(夂)걸음 하는 잔칫날 → 경사·축하
부품 이름: 广 = **집** ← 지금은 '사슴' [구성도 '사슴'] / 心 = 마음 / 夂 = 발


## 厂 = 벼랑
이미 이 이름으로 쓰는 글자 14자. 예: 石 벼랑(厂) 밑에 굴러떨어진 돌덩이(口) → 돌 ／ 原 벼랑(厂) 밑에서 샘물(白小)이 처음 솟아나는 곳 → 근원

### 灰 (재 회)
구성: 厂(손 · 뜻) + 火(불 · 뜻)
유래: 뜻+뜻: 손으로 집을 만큼 식은 불, 곧 재를 뜻함.
지금 외우기: 손(厂)으로 집어도 안 뜨거운 식은 불(火) → 재
부품 이름: 厂 = **벼랑** ← 지금은 '손' [구성도 '손'] / 火 = 불


## 疒 = 병
이미 이 이름으로 쓰는 글자 14자. 예: 痛 병(疒)이 물 솟듯(甬) 욱신욱신 치밀어 → 아프다 ／ 疫 병(疒)이 몽둥이(殳)처럼 마을을 휩쓰는 → 전염병

### 病 (병 병)
구성: 疒(병들어 누움 · 뜻) + 丙(남녘 병 · 소리 ヘイ)
유래: 뜻+소리: 병이 무거워짐.
지금 외우기: 병들어 누워(疒) 남녘(丙) 창 볕만 쬐며 끙끙 → 병·앓다
부품 이름: 疒 = **병** ← 지금은 '누워' [구성도 '병들어 누움'] / 丙 = 남녘


## 虫 = 벌레
이미 이 이름으로 쓰는 글자 14자. 예: 風 책상(几) 밑 벌레(虫)까지 날려 보내는 → 바람 ／ 強 활(弓)에도 끄떡없는 내(厶) 벌레(虫) → 강하다

### 虹 (무지개 홍)
구성: 虫(벌레·뱀 · 뜻) + 工(장인 공 · 소리 コウ)
유래: 뜻+소리: 무지개를 하늘의 뱀·용으로 여긴 데서를 뜻함.
지금 외우기: 장인(工)이 하늘에 걸어 놓은 알록달록 뱀(虫) → 무지개
부품 이름: 工 = 장인 / 虫 = **벌레** ← 지금은 '뱀' [구성도 '벌레·뱀']


## 子 = 아이
이미 이 이름으로 쓰는 글자 13자. 예: 字 집(宀)에서 아이(子)가 익히는 → 글자 ／ 学 덮개(冖) 지붕 아래 아이(子)를 두 손(⺍)으로 이끄는 → 배우다

부품 이름: 能 = **능하다** ← 지금은 '곰' [구성도 '곰'] / 灬 = 불


## 夭 = 어여쁘다
이미 이 이름으로 쓰는 글자 2자. 예: 妖 어여쁜(夭) 여자(女)가 몸을 배배 꼬며 홀리는 → 요사하다 ／ 沃 물(氵) 댄 땅에 싹이 예쁘게(夭) 자라는 → 기름지다

### 笑 (웃을 소)
구성: 竹(대나무 · 뜻) + 夭(사람 · 뜻)
유래: 뜻+뜻: 竹(대나무)+夭(몸을 젖힌 사람)으로 봄. 몸을 흔들며 웃음(의견이 갈림).
지금 외우기: 대나무(竹)가 바람에 흔들리듯 사람(夭)이 허리 젖혀 깔깔대는 → 웃다
부품 이름: 竹 = 대나무 / 夭 = **어여쁘다** ← 지금은 '사람' [구성도 '사람']


## 圣 = 줄
이미 이 이름으로 쓰는 글자 1자. 예: 径 베틀 줄(圣)처럼 곧게 뻗어 걸어가는(彳) 빠른 길 → 지름길

### 経 (지날 경)
구성: 糸(실 · 뜻) + 圣(세로 실 · 뜻·소리 ケイ)
유래: 뜻+소리: 糸(실)+巠(베틀에 세로로 건 실, ケイ가 소리). 천의 세로 실에서 지나다·경전. 일본에서는 巠을 圣으로 씀.
지금 외우기: 베틀에 실(糸)을 세로(圣)로 걸어 위에서 아래로 쭉 → 지나다
부품 이름: 糸 = 실 / 圣 = **줄** ← 지금은 '세로' [구성도 '세로 실']


## 扁 = 작다
이미 이 이름으로 쓰는 글자 2자. 예: 偏 작은(扁) 쪽배에 탄 사람(亻)이 한쪽으로 쏠린 → 치우치다 ／ 遍 작은(扁) 편지 들고 온 동네 길(辶)을 빠짐없이 → 두루

### 編 (엮을 편)
구성: 糸(실 · 뜻) + 扁(나무패 · 뜻·소리 ヘン)
유래: 뜻+소리: 글 적은 대나무 패(扁, ヘン)를 실(糸)로 차례대로 꿰어 책을 엮음을 뜻함.
지금 외우기: 글 적은 나무패(扁)를 실(糸)로 줄줄이 꿰어 한 권으로 만든 → 엮다
부품 이름: 扁 = **작다** ← 지금은 '나무패' [구성도 '나무패'] / 糸 = 실


## 千 = 천
이미 이 이름으로 쓰는 글자 1자. 예: 重 곡식 자루를 지고 천(千) 리(里) 길을 가니 → 무겁다

### 舌 (혀 설)
구성: 千(갈라진 혀 · 모양) + 口(입 · 모양)
유래: 그림: 입(口)에서 갈라진 혀를 내민 모양임.
지금 외우기: 입(口) 위로 끝 갈라진 혀(千)를 날름 → 혀
부품 이름: 口 = 입 / 千 = **천** ← 지금은 '혀' [구성도 '갈라진 혀']


## 吉 = 길하다
이미 이 이름으로 쓰는 글자 1자. 예: 結 길한(吉) 날 실(糸)로 매듭을 꼭 지어 → 맺다

### 舎 (집 사)
구성: 人(지붕 · 모양) + 吉(기둥 터 · 모양)
유래: 그림: 지붕·기둥과 터(口)를 갖춘 집 모양(옛 사전 풀이). 余(ヨ)가 소리를 나타낸다고 보기도 함. 나그네가 묵는 집.
지금 외우기: 지붕(人)을 기둥 박은 터(吉) 위에 얹은 → 집
부품 이름: 人 = 지붕 / 吉 = **길하다** ← 지금은 '터' [구성도 '기둥 터']


## 巴 = 사람
이미 이 이름으로 쓰는 글자 1자. 예: 肥 사람(巴) 몸에 살(月)이 뒤룩뒤룩 붙은 → 살찌다

### 色 (빛 색)
구성: 𠂊(사람 · 뜻) + 巴(꿇은 사람 · 뜻)
유래: 뜻+뜻: 𠂊(사람 人이 변한 꼴)+巴(꿇어앉은 사람 卪이 변한 꼴). 옛 사전은 이 둘로 얼굴빛을 나타낸다고 봄(의견이 갈림). '빛깔'.
지금 외우기: 윗사람(𠂊) 앞에 꿇어앉아(巴) 얼굴빛이 붉어진 → 색·빛깔
부품 이름: 𠂊 = 사람 / 巴 = **사람** ← 지금은 '꿇어앉아' [구성도 '꿇은 사람']


## 列 = 줄
이미 이 이름으로 쓰는 글자 2자. 예: 例 사람(亻)이 줄(列) 선 이들 앞에서 시범 보이는 → 보기·예 ／ 烈 불(灬)이 줄지어(列) 활활 → 세차다

### 裂 (찢을 렬)
구성: 列(가름 · 뜻·소리 レツ) + 衣(옷 · 뜻)
유래: 뜻+소리: 衣(옷)이 뜻, 列(レツ)은 소리도 내고 뜻(가름)도 보탬. 천을 찢음.
지금 외우기: 옷(衣)을 북 갈라(列) 두 쪽 낸 → 찢다
부품 이름: 衣 = 옷 / 列 = **줄** ← 지금은 '갈라' [구성도 '가름']


## 复 = 돌아오다
이미 이 이름으로 쓰는 글자 2자. 예: 復 남쪽으로 갔던(彳) 제비가 봄에 옛 처마로 돌아오는(复) → 돌아오다 ／ 腹 실컷 먹고 돌아와(复) 몸(月)을 통통 두드리는 → 배

### 複 (겹칠 복)
구성: 衤(옷 · 뜻) + 复(거듭 · 뜻·소리 フク)
유래: 뜻+소리: 衤(옷)+复(거듭, フク가 소리). 안을 댄 겹옷(옛 사전 풀이) → 겹치다.
지금 외우기: 옷(衤)을 거듭(复) 껴입어 두툼한 → 겹치다
부품 이름: 衤 = 옷 / 复 = **돌아오다** ← 지금은 '거듭' [구성도 '거듭']
