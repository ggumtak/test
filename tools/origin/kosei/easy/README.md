# 유래 쉬운 말 다듬기 (2026-11-08)

사용자 요청: 유래에 어려운 한자어나 낯선 말이 있으면 이해하지 못해 외우지도 못하니, 모두 쉬운 말로 풀 것. 부수는
정확하게, 유래는 부수·구성과 이어져 이해하기 쉽게. 고른 방향: **쉬운 말 + 구성과 연결, 사실은 그대로**(지어낸
이야기는 외우기 칸에만).

## 방법
- `make_inputs.py 12` → `in-N.txt`(묶음마다 178자: 훈음, 부수, 구성, 유래, 외우기), `list-N.txt`.
- 묶음마다 작성(Sonnet) → 독립 검토(Opus): `BRIEF.md`를 따라 `easy-N.tsv`(바꾼 글자만: 한자, 새 구성, 새 유래, 이유).
  검토자는 작성자의 줄마다 사실·유보 표현·쉬운 말·구성과의 일치를 따져 고치거나 되돌리고, 작성자가 놓친 줄을
  더함. `check.py N`이 형식·유형·길이·음독·유보 표현 유지·구성 모양과 역할 불변을 검사.
- `easy-final.tsv`, `memo-final.tsv`: 리드의 마지막 손질. 같은 소리 부분의 설명을 통일하고(丁 '장정 정', 艮 '그칠
  간', 亥 '돼지 해', 尞 '모닥불 료', 勺 '국자' 등, 외우기의 말과 맞춤), 전체를 다시 훑어 남은 어려운 말을 풂.
- `../merge.py`는 이 폴더를 모든 보정 파일 **다음**에 적용(이 작업이 병합된 결과를 다시 썼기 때문).

## 결과
262자: 유래 232줄, 구성 설명 54줄, 외우기 4줄. 학습자가 모를 말(녹봉·보루·시렁·점괘·주살·화톳불·천간 등)은 일상어로
바꾸거나, 그 말이 글자의 뜻 자체일 때는 남기고 괄호로 풀었고(제후(왕 아래서 땅을 다스리던 사람)), 유래가 구성과
같은 부품 이름·같은 말을 쓰도록 맞췄습니다(師 '왼쪽' → 𠂤, 豪 '高를 줄인 꼴' → 亠+口+冖). '약식 글자'는 줄여
만든 것인지 다른 꼴로 바꾼 것인지에 따라 '줄인 글자'와 '간단한 글자'로 나눴습니다(艶·蚕·覇·軟은 바꾼 것).
