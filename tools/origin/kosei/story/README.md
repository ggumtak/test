# 외우기 다시 쓰기 (2026-11-08)

사용자: "貼의 `돈(貝) 위에 점(占)찍듯 딱지를 → 붙이다`가 무슨 말인지 아무리 봐도 이해가 안 되고, 유래와 외우기가 너무
달라 볼수록 더 헷갈린다." 그래서 외우기가 지켜야 할 두 가지를 정했습니다(`BRIEF.md`).
1. 혼자 읽어도 말이 된다: 한자를 모르는 사람이 이 줄만 보고 왜 그 뜻이 되는지 한 문장으로 말할 수 있다.
2. 구성·유래와 같은 이야기다: 뜻 부분은 구성 설명과 같은 말로 부르고, 유래를 쉬운 장면으로 옮길 수 있으면 그대로 쓴다.

## 방법 (묶음마다, 12묶음)
- 독자 시험(Sonnet): 유래를 가린 입력(`rin-N.txt`: 훈음·구성·외우기)으로 지금 외우기를 모두 판정 → `r-N.tsv`
  (OK / 불명 / 어긋남 / 어려움). 2,136줄 중 약 23%가 걸림.
- 다시 쓰기(Sonnet): 걸린 줄을 유래 이야기로 다시 쓰고, 유래에 남은 어려운 말도 풂 → `story-N.tsv`.
- 검토(Opus): 줄마다 말이 되는지·구성과 같은지·유래를 지어내지 않았는지·보이는 모양인지 따져 고치거나 되돌림.
- `story-final.tsv`: 리드의 마지막 손질(독자는 OK였지만 구성과 어긋난 宿 審 寺 定 垂 声 喉 喪), 되돌린 줄(来 灯).
- `check.py N`: 형식(45자, `… → 뜻`), 보이는 모양, 중국 간체, 유래를 고쳤을 때 유형·음독·유보 표현 유지.

## 결과
외우기 552줄, 유래 7줄(貼의 '저당 잡히다' → '물건을 맡기고 돈을 빌리다' 등). `../merge.py`가 이 폴더를 마지막에 적용합니다.
