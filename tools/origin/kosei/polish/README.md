# 외우기 다듬기: 약한 줄만 골라 바깥 작가에게 맡기기 (2026-11-10)

사용자 요청: 작문은 제미나이가 더 잘하니, 맡길 만한 부분이 정말 있으면 요청 문서로 만들어 줄 것. 억지로 맡기지는 말 것.

## 무엇을 맡기고 무엇을 맡기지 않았나

- **맡김: 외우기 215줄.** 외우기는 사실이 아니라 솜씨의 문제라 다른 작가의 문체가 도움이 될 수 있고, 돌아온 줄은 규칙
  검사와 비교 채점으로 걸러 낼 수 있습니다.
- **맡기지 않음: 유래·구성·부수.** 사실과 자료 구조의 문제이고, 앱의 다른 줄·획 그림 색과 맞물려 있어 저장소 안에서
  확인해야 합니다. 요청 문서는 이 줄들을 고치지 말고 메모만 달라고 합니다.
- **맡기지 않음: 나머지 외우기 1,921줄.** 선별에서 표시되지 않은 줄입니다. 잘 작동하는 줄을 취향으로 다시 쓰면 줄 사이
  이름 통일이 깨질 위험만 생깁니다.

## 선별 (`GRADE.md`, `in-N.tsv` → `grade-N.tsv`)

2,136줄을 8묶음으로 나눠, 묶음마다 독립 채점자(Opus)가 학습자 눈으로 전부 읽고 "더 나은 줄이 가능한" 줄만 약점 코드와
한 줄 진단을 붙여 표시했습니다. 215줄(10%): 뚜렷이 약한 줄 26, 더 좋아질 수 있는 줄 189.

| 약점 | 줄 수(겹침 있음) |
|---|---|
| W3 끼워 넣은 부품(지워도 장면이 같음) | 79 |
| W2 장면에서 뜻이 안 나옴 | 63 |
| W4 뜻을 그대로 말함 | 41 |
| W1 장면이 안 그려짐 | 34 |
| W5 어색한 문장 | 22 |
| W6 유래와 따로 놂 | 5 |
| W7 빠진 부품 | 1 |

채점자도 모델이라 사람의 판단과 다를 수 있습니다. 채점자들이 공통으로 애매하다고 한 곳: 부품의 뜻이 곧 글자의 뜻일 때의
W4(網의 罔 '그물'), 소리 말장난(壬 → '임무')을 방법으로 볼지 W3으로 볼지.

## 요청 문서 (`make_request.py` → `외우기_다듬기_요청.md`, `requested.txt`)

문서 하나로 완결됩니다: 읽는 사람, 카드의 줄, 좋은 외우기의 조건, 반드시 지킬 규칙 8개, 예시 3개, 답의 형식, 그리고
한자마다 훈음·구성·유래·지금 외우기·진단을 담은 표(뚜렷이 약한 줄 먼저).

## 돌아온 답 처리

1. 답을 파일로 저장하고 `python3 tools/origin/kosei/polish/check_return.py 답.txt --accept`
   - 오류(쓸 수 없음): 요청하지 않은 한자, `장면 → 뜻` 꼴이 아님, → 뒤의 뜻을 바꿈, 50자 초과, 괄호 밖 한자,
     이 글자에 없는 모양.
   - 확인(사람이 판단): 45자 초과, 구성의 부품이 빠짐, 구성과 다른 이름.
2. 통과한 줄을 지금 줄과 나란히, 어느 쪽이 새 줄인지 가린 채 같은 기준(`GRADE.md`)으로 비교 채점해 **더 나은 줄만** 받습니다.
3. 받은 줄을 `../link/link-polish.tsv`(한자, 구성, 유래, 외우기, 이유; 앞의 두 칸은 빈칸)에 넣고
   `python3 tools/origin/merge.py`, `python3 tools/origin/kosei/link/ship_check.py`, 앱 테스트.

다듬을 때 지킨 것:

- **길이**: 돌아온 줄은 부품을 다 넣느라 절이 많았습니다. 장면 하나만 남기고 꾸밈말을 뺐습니다.

  党의 儿은 구성대로 '검은').
- **유래**: 돌아온 장면이 유래와 다른 이야기로 흘러간 줄은 유래 쪽으로 되돌렸습니다(救 막대로 쳐서 막음, 済 강을 건넘,
  潰 둑이 터짐, 篤 느릿느릿 걷는 말).
- **받지 않은 줄**: 1차에서 진 71줄과 비긴 2줄, 2차에서 비기거나 진 4줄은 지금 줄 그대로입니다. 読·続의 売를
  '책상'·'실감개'로 부른 줄처럼 다른 글자와 이름이 어긋나는 줄도 여기에 듭니다.
