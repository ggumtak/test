# 8묶음 (羅 … 設, 200자) 다시 읽기

## 고친 것
- 至: 구성 고침 — 맨 위 一(1획)이 어느 부품에도 없었음(事의 一과 같은 경우). 자유 작성으로 一+厶(날아온 화살) + 土.
- 興: 구성·유래 고침 — 아래 두 손의 一(14획)이 빠지고 八만 있었음. 一+八(아래의 두 손)로, 유래도 '아래는 一+八 꼴'. 위는 부수 𦥑로 써서 빨간색 유지.
- 膝: 구성 고침 — 桼의 가운데 人(9·10획)이 빠진 木+氺였음. 木+人+氺(옻 桼).
- 舞: 구성 고침 — 丿+一이 윗부분 8획 중 2획만 가리킴. 그 꼴을 적을 글자가 없어 원형 無(춤추는 사람, 灬는 빠짐)로 씀(観의 雚과 같은 방식).
- 華: 구성 지움 — 丨 한 획 이름이 아래 7획 전체를 대신함. 그 꼴을 나타낼 글자(𠌶 등)가 휴대폰 글꼴에 없고, 유래가 위(艹)·아래를 말로 설명하므로 '-'.
- 薦: 구성 고침 — 广+灬가 廌의 가운데 6획을 빠뜨림. 아래는 廌 그대로 보이므로 艹(풀) + 廌(해태).
- 血: 구성 더함 — 유래가 皿(그릇)+丿(피)로 설명하는데 구성 줄이 없었음. 丿(담긴 피 · 기호) + 皿(그릇 · 뜻).
- 色: 구성 고침 — 위는 ⺈(𠂊) 꼴인데 비슷한 勹로 적혀 있었음(외우기는 이미 ⺈). 負·免처럼 𠂊.
- 託: 구성 고침 — 乇의 설명 '사나울 학'은 虐의 훈음(kanji.tsv 乇 줄이 虐 이체로 잘못 이어짐). 乇은 풀잎 탁(외우기의 '풀잎'과도 맞음). 같은 오류가 宅(다른 묶음)에도 있음.
- 職: 구성 고침 — 드문 글자 戠에 아무 설명이 없었음. '音과 戈를 합친 꼴'(뜻이 확실하지 않아 보이는 조각으로 풂).
- 船: 구성 고침 — 드문 글자 㕣에 설명이 없었음. 산속의 늪 연.
- 裁: 구성 고침 — 드문 글자 𢦏에 설명이 없었음. 다칠 재(옛 사전: 傷也).

## 생각하고 그대로 둔 것 (아슬아슬한 것만)
- 羽: 그대로 — 习은 중국 간체자이기도 하나 일본 인쇄의 반쪽 꼴 그대로이고 '깃털'로 풀어 둠.
- 茎: 그대로 — 圣(간체자 신호)은 보이는 꼴 그대로, '巠을 줄인 꼴'로 풂(径·経·軽과 같음).
- 虚: 그대로 — 业(간체자 신호)는 보이는 꼴 그대로, '언덕 丘가 변한 꼴'로 풂.
- 腹·複: 그대로 — 复(간체자 신호)은 復의 오른쪽과 같은 본래 부품, 보이는 꼴 그대로.
- 親: 그대로 — 亲(간체자 신호)은 新에도 있는 본래 부품(立+木), 소리 부분이라고 유래가 말함.
- 衡: 그대로 — 가운데는 엄밀히 𩵋(아래가 大)이나 parts.tsv 원형 魚로 적고 설명이 '뿔 角과 大가 변한 꼴', 유래도 '魚 비슷한 꼴'이라 이어짐.
- 能: 그대로 — 䏍는 드문 글자지만 설명에 厶(머리)·月(몸)을 밝힘. 나누려면 자유 작성이 필요해 둠.
- 覇: 그대로 — 䩗 설명에 革(소리)·月(달)을 밝힘.
- 観: 그대로 — 3획이 부품 밖이지만 雚(위를 줄여 씀) 한 단위가 왼쪽 전체를 가리키고 획 색도 파랑.
- 蔑: 그대로 — 글꼴에서 아래가 戌처럼 보이나 KanjiVG 부품과 유래 모두 戍(사람+창).
- 考: 그대로 — 丂에 설명이 없으나 두 획의 간단한 꼴이고 외우기가 지팡이로 그림을 줌.
- 脱·薦·行: 외우기 그대로 — 兑·廌·亍(상용 밖 신호)는 보이는 꼴 그대로를 가리킴.
- 臼·舟: 그대로 — 외우기가 비어 있음. 口·山·川·木처럼 그림 글자는 비워 둔 것으로 보여 새로 만들지 않음.
- 葛: 그대로 — 구성·유래·외우기는 맞음. 다만 kanji.tsv 획수 11은 그림의 12획(2010 상용 꼴)과 다름(이 검토 밖).

- 유래 1자 (興)
- 외우기 0자
