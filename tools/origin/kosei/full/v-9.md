# 묶음 9 (許 … 酪, 200자) 검토

## 고친 것
- 誉: 구성·유래 고침 — 4획 一이 어느 부품에도 없음(⺍+八만 적힘) → ⺍+一+八. 유래의 꼴 설명도 '⺍·一·八'로 맞춤(사실은 그대로)
- 説: 구성 고침 — 兑의 설명 '일본에서는 兑로 씀'이 제 꼴을 되풀이해 헷갈림 → 기쁠 태(税·脱·鋭·閲과 같게)
- 謡: 구성 고침 — 䍃 글꼴은 윗부분이 爫가 아니어서 일본 인쇄 꼴과 다름 → 爫+缶(䍃의 위를 바꾼 꼴)
- 谷: 구성 넣음 — 유래가 口·八로 풀이하는데 줄이 없었음. 위 4획은 인쇄 꼴대로 八+人(외우기와 같음)
- 象: 구성 고침 — 3~5획(冂+丨, 아래는 豕의 一로 닫힘)이 어느 부품에도 없음 → 𠂊+冂+丨(코끼리 머리 쪽)
- 貫: 구성 고침 — 모양을 毋로 적고 설명에 '毋가 아님'이라 해 모순. 일본 인쇄 꼴(3획이 세로획)은 毌
- 賓: 구성 고침 — 4획 一이 부품 밖 → 宀+一+少
- 遇: 구성 고침 — 禺 설명 '땅 이름 옹'은 소리 グウ(우)와 안 맞고 외우기의 원숭이와도 어긋남 → 긴꼬리원숭이 우
- 那: 구성 고침 — 二만 적혀 1·4획(刀 꼴)이 빠짐 → 刀+二(冄이 변한 꼴). 그림 메모: 1·4획도 파랗게
- 論: 외우기 고침 — 상용 밖 글자 亼(모으다) 대신 보이는 그대로 人·一
- 選: 외우기 고침 — 일본 인쇄 꼴은 己己(ㄹ 꼴)인데 '뱀(巳)'이라 부름 → 몸(己)

## 살펴보고 그대로 둔 것 (애매했던 것만)
- 赤: 그대로 — 유래는 大+火라 하나 지금 아랫부분 4획이 글자 꼴이 아니라 부품으로 적을 수 없음
- 豆·身·車: 그대로 — 유래가 부품으로 풀지 않음(구성 줄 없음이 맞음)
- 那 외우기: 그대로 — '두(二)'로 왼쪽을 가리켜 충분하고, 새 이야기가 뚜렷이 낫지 않음
- 誇 夸·貯 宁·邦 丰: 그대로 — 간체자 신호지만 셋 다 그 글자가 실제 부품(본래 있던 글자)
- 軽 圣: 그대로 — 経·径·茎과 같은 표기이고 '巠을 줄인 꼴'이라 설명됨
- 送 关: 그대로 — 関·咲·朕과 같은 표기, 설명 있음
- 譲 㐮(줄여 쓴 꼴): 그대로 — 유래가 '襄을 줄여 씀'으로 바로 이어 줌
- 迎 卬(자기 앙)·遍 扁(특별할 편): 그대로 — kanji.tsv 훈음 그대로이고 틀렸다고 할 근거 부족
- 逓 외우기 범(乕): 그대로 — 乕는 虎의 다른 꼴, 虒도 뿔범이라 유래와 어긋나지 않음
- 貿 卯: 그대로 — 일본 꼴의 오른쪽이 刀처럼 보이나 같은 부품의 글꼴 차이

## 묶음 밖 참고
- 偶·隅도 禺를 '땅 이름 옹'으로 적음(遇와 같은 문제). 挙는 誉와 같은 一 누락(제미나이 묶음에서 다룸). 揺는 謡와 같은 䍃 문제.

- 자유 작성(!) 7, 그림 메모 1(那)
