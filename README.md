# 한자 바로보기

아무 앱에서 한자를 꾹 눌러 선택하고 텍스트 선택 메뉴의 **한자**를 누르면, 지금 화면 위에 카드가 뜹니다.
카드에는 선택한 단어(가나만 고르면 한글 발음도)와, 한자마다 한국 훈음(気 → 기운 기, 한국 정자 氣), 음독·훈독과
한글 발음(メイ(메이)), 획수, 학년이 나옵니다. 인터넷 없이 바로 보입니다.

- 한자 줄이나 **한자사전**을 누르면 네이버 한자사전, **일본어사전**을 누르면 네이버 일본어사전이 열립니다.
- **Anki 한 번 탭**: `app/src/main/assets/anki-tap.html`(앱의 'Anki용 코드 복사')을 카드 템플릿 맨 아래에 붙이면,
  AnkiDroid에서 한자·가타카나를 탭하거나, 드래그한 뒤 선택 아래에 뜨는 '한자' 버튼을 누르면 카드가 뜹니다
  (`hanja://lookup?q=…&s=…` 링크). v3로 바꿀 때는 앞면·뒷면의 기존 한자 바로보기 코드를 지우고 교체합니다.
- **이 문장에서의 읽기**: Anki에서 탭했거나 두 글자 이상 선택하면 Claude(Haiku 5.5, 생각 단계 없음, 구조화 출력)가 문장을 보고
  그 자리의 발음과 한자별 읽기를 판정합니다. 화면 형식은 그대로이고, 머리의 읽기와 한자 줄의 "단어" 읽기만 그 결과로 바뀝니다
  (今日は雨 → きょう). 답은 문장 포함 여부·읽기 조합을 검증하고 기기에 저장해 같은 문장은 다시 묻지 않습니다. 저장된 답은 API 키 없이도 재사용하며, 카드의 첫 화면에 바로 나옵니다.
- **예문**: 한자 정보 아래 "예문 보기"를 누르면, 질문에 쓰는 모델이 그 단어(카드 문장과 같은 뜻)로 쉬운 예문 3개를
  만들어 문장·읽기(히라가나)·뜻 순서로 보여 줍니다. 만든 예문은 저장해 두어 다시 열면 바로 뜹니다.
- **질문**: 고른 글자가 입력창에 들어가고, 이어 쓴 질문을 보내면 설정에서 고른 모델(기본 Sonnet 5.5)이 답합니다. 대화를 이어 갈 수 있습니다.
- **Claude 설명**: 앱 아이콘에서 넣은 Claude API 키로 설정에서 고른 모델에 물어, 답을 카드 안에 글자가 나오는 대로 보여 줍니다.
  카드에 이미 있는 훈음·음독·훈독은 되풀이하지 않고 【뜻】【한국어 연결】【외우기】【읽기 주의】【자주 쓰는 말】 중 쓸 말이 있는 항목만 8줄 안에서 짧게 씁니다.

## 답 보기 좋게 (2026-11-03)

- AI 답은 정해진 가벼운 표시만 쓰고 앱이 그려 줍니다(`Rich.kt`): 【항목】은 강조색 굵게, `- ` 줄은 글머리표와 들여쓰기,
  `→ ` 번역 줄은 회색, `**굵게**`. 일본어 읽기는 `電気(でんき)`처럼만 쓰게 하고 앱이 한글 발음을 붙입니다(`(でんき 덴키)`,
  읽기는 작고 회색, 한글은 강조색). 카드 위쪽과 같은 발음 표기가 되고, AI가 한글 발음을 쓰는 토큰도 줄어듭니다.
- 설명·질문은 친근한 해요체로, 결론 먼저, 짧은 줄. 질문은 한국어와 같은 점·헷갈리는 점(は/が와 은는/이가 등)을 짚습니다.
- 외우기: 한자를 부품으로 나눠 짧은 이야기로 묶는 방식(부품 분석이 통째 암기보다 기억이 오래갔다는 연구가 있습니다).
  지어낸 이야기는 진짜 어원처럼 쓰지 않게 했습니다. 한국 한자음과 일본어 음독의 대응은 규칙이 아니라 경향이라, 눈에 보일 때만 씁니다.
- 예문: 실제로 말하거나 들을 법한 구체적인 장면, 반말·존댓말·다른 상황을 섞고 가능하면 단어의 형태나 조사를 바꿔 쓰임을 보여 줍니다.
- 검증 탈락 줄이기(2026-11-04): 프롬프트와 스키마 설명에 앱의 검사 규칙을 그대로 적었습니다. 오쿠리가나 단어는 `食(た)べる`처럼
  한자 바로 뒤에 읽기를 쓰게 해 한글 발음이 붙고, 읽기 판정은 연탁·촉음 분할과 々·반복 한자 규칙을, 후보 줄은 `훈음 | gloss: 뜻 / 뜻`으로
  나눠 뜻풀이를 훈음으로 베끼지 않게 했고, 예문 읽기 줄은 숫자도 가나로(3時 → さんじ) 쓰게 했습니다.

## 업데이트

앱을 열면 GitHub `latest` 릴리스의 새 빌드를 확인합니다. 새 버전이 있으면 맨 위 버튼이 "빌드 N 설치"로 바뀌고, 누르면
내려받아 Android 설치 화면이 뜹니다(처음 한 번은 이 앱의 '알 수 없는 앱 설치' 허용이 필요합니다). 모든 CI 빌드가 같은 키로
서명되므로 덮어쓰기 설치되고 설정·API 키가 유지됩니다(`update/AppUpdater.kt`).

## 설치

push할 때마다 GitHub Actions가 서명된 APK를 만들어 이 저장소의 `latest` 릴리스에 올립니다.
휴대폰에서 릴리스 페이지를 열고 `.apk`를 눌러 설치합니다(처음 한 번은 "출처를 알 수 없는 앱" 허용이 필요합니다).

## 구조

- `app/src/main/java/com/ggumtak/hanja/` — `LookupActivity`(선택 메뉴 카드), `MainActivity`(사용법·API 키),
  `KanjiStore`/`Kanji`/`KanjiText`(자료·순수 로직), `ClaudeClient`(스트리밍 요청). 외부 라이브러리는 쓰지 않습니다.
- `app/src/main/assets/words.tsv` — `tools/build_word_data.py`가 JMdict에서 만든 단어 읽기(部屋 → へや). 카드 머리에
  단어 읽기를, 한자 줄에 "이 단어에서 읽는 음"을 보여 주고, 단어 전체로 읽는 말(숙자훈)은 따로 알려 줍니다.
- `app/src/main/assets/kanji.tsv` — `tools/build_kanji_data.py`가 만든 자료(13,436자). 상용한자 2,136자에는
  일본어에서 쓰는 뜻을 쉬운 현대 한국어로, 많이 쓰는 순서대로 담은 열과 영어 뜻의 한국어 열이 붙습니다
  (`tools/gloss`: Claude가 세 묶음으로 쓰고 다른 검토 단계가 전부 다시 읽어 258줄을 고친 `gloss.tsv`), 그리고
  일본어 쓰임에 가장 자연스러운 훈음을 앞에 둔 훈음 열(`hun.tsv`: 所 → 곳 소, 바 소)이 붙습니다. 카드의 큰 줄은 이 훈음입니다. 다시 만들 때 쓰는 원본과
  명령은 스크립트 첫머리에 적혀 있습니다.

## Anki 중심 개선 (2026-11-03)

- 긴 카드도 탭한 위치 주변 문장을 전달합니다. 후리가나(`rt/rp`)는 문맥에 넣지 않습니다.
- 탭 이벤트가 부모로 전달되어 카드까지 뒤집히는 일을 막습니다. 앞면→뒷면 전환 후 드래그 버튼도 다시 만듭니다.
- 새로 들어온 텍스트만 찾아 링크로 바꿔 큰 카드의 반복 순회를 줄입니다. 확장 한자도 한 글자로 처리합니다.
- 문맥 훈음은 알려진 후보만 강조합니다. 맞는 후보가 없으면 AI에 빈 답을 허용합니다.
- 단어 전체 읽기와 글자별 읽기를 합쳐 검사합니다. 반복 한자처럼 글자별 배당이 불확실하면 전체 읽기를 유지합니다.
- 사전 읽기를 분해하지 못했다는 이유만으로 숙자훈이라고 단정하지 않습니다.
- 저장 공간이 차도 오래된 일부만 정리합니다. 이전 검증 방식의 답은 새로 확인합니다.
- AI 설명은 50ms 단위로 화면에 반영하며, 위쪽을 읽는 중에는 끝으로 끌어내리지 않습니다.

## 속도 최적화 (2026-11-03)

- **생각 단계 끄기**: 읽기 판정은 Haiku 5.5의 생각 단계를 끄고 보냅니다. 질문·설명·예문은 '생각하는 정도'가 낮음(새 기본값)이면
  Haiku는 생각 끔, Sonnet 5.5는 `between_tools`(생각 없음)로 바로 답을 쓰기 시작합니다. Opus 5.5는 생각을 끌 수 없어 짧게만 생각합니다.
  중간·높음을 고르면 전처럼 먼저 생각합니다(`ClaudeRequest.thinking`).
- **영어 지시문, 한국어 답**: 모든 AI 지시문과 스키마 설명을 영어로 바꿔 입력 토큰을 줄였고, 답(설명·질문·예문 번역)은 한국어로
  쓰게 했습니다. 읽기 판정의 후보 훈음은 카드에 보이는 한자만 보냅니다(긴 Anki 문장에서 최대 64자 → 최대 8자).
- **캐시**: 지시문에 캐시 표시를 달고(512토큰 이상이면 재사용), 질문 대화는 쌓인 대화도 캐시해 이어지는 질문의 첫 글자가 빨라집니다.
- **연결 미리 열기**: 카드가 열리면(읽기 판정을 보내지 않을 때)과 질문 창을 열 때 API 서버 연결(DNS·TLS)을 미리 열어 둡니다.
- **저장된 답**: 수 MB짜리 SharedPreferences XML 하나 대신 답마다 작은 파일 하나(`files/answers/…`, 최근 사용 순 3,000개)에
  둡니다. 저장할 때 파일 전체를 다시 쓰지 않고, 처음 읽을 때 전체를 불러오지 않습니다. 이전 빌드의 답은 첫 실행 때 한 번 옮깁니다.
  예문 저장분도 화면 스레드 밖에서 읽습니다.
- **안전장치**: API가 이 설정(생각 끄기·캐시 표시)을 400으로 거절하면 이전 빌드와 같은 요청으로 한 번 다시 보내고, 앱을 다시 켤 때까지 그 방식을 씁니다.
- TTS(읽어 주기)는 넣지 않았습니다.

검증: `./gradlew testDebugUnitTest assembleRelease`; Anki 템플릿은 Playwright 설치 후
`node tools/test_anki_tap.cjs`로 Chromium에서 검사합니다. GitHub Actions에서도 두 검사를 실행합니다.
실제 AnkiDroid의 intent 이동·복귀, Android 설치 화면, 유료 API의 의미 판정은 휴대폰에서 확인해야 합니다.
